## Quick Reference

The project constitution defines all core principles and development standards. Key points:

- **Component-First Architecture**: All functionality must be React components
- **TypeScript Strict Mode**: Mandatory type safety
- **Storybook Documentation**: Every component must have stories
- **CSS Modules**: Scoped styling only
- **Biome**: Linting and formatting
- **English Language**: All code, comments, and documentation must be in English
