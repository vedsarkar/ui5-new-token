# Colors

All color tokens are auto-generated from Figma design tokens. The mapping between Figma token names and CSS variables is defined in `tokens/token-map.json`.

**Usage:** `var(--reltio-color-{name})` — click any variable name to copy it.

**Regenerate:** `npm run build-tokens`
