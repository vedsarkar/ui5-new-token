# Design Tokens

The Reltio Design Platform mirrors [SAP Horizon](https://github.com/SAP/theming-base-content) design tokens 1:1. Every `--sap*` CSS variable is available on `:root` when `variables.css` is loaded. Colors **must** use these tokens — never hardcode hex values.

## Usage

Include `variables.css` and `fonts.css` in your page `<head>`, then set `data-theme` on any ancestor element:

```html
<link rel="stylesheet" href="variables.css" />
<link rel="stylesheet" href="fonts.css" />
<div data-theme="horizon-light">...</div>
```

**CSS** — reference any variable: `color: var(--sapBrandColor)`, `background: var(--sapErrorBackground)`, etc.
