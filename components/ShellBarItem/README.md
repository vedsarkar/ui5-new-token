# ShellBarItem

`ShellBarItem` is a custom action button in the `ShellBar`.

`ShellBarItem` is re-exported 1:1 from `@ui5/webcomponents-react/ShellBarItem`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Place in the `ShellBar` to add product-specific actions; set `icon` and `text`.
