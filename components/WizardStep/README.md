# WizardStep

`WizardStep` is one step in a multi-step `Wizard` flow.

`WizardStep` is re-exported 1:1 from `@ui5/webcomponents-react/WizardStep`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `Wizard`; set `titleText`, `selected`, `icon`.
