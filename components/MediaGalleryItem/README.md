# MediaGalleryItem

`MediaGalleryItem` is one media entry (thumbnail + full view) in a `MediaGallery`.

`MediaGalleryItem` is re-exported 1:1 from `@ui5/webcomponents-react/MediaGalleryItem`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `MediaGallery`; put the thumbnail in the `thumbnail` slot.
