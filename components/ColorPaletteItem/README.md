# ColorPaletteItem

`ColorPaletteItem` is a single selectable swatch in a `ColorPalette`.

`ColorPaletteItem` is re-exported 1:1 from `@ui5/webcomponents-react/ColorPaletteItem`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `ColorPalette`; set `value` to any CSS color.
