# ToolbarSelect

`ToolbarSelect` is an inline dropdown selector inside a `Toolbar`.

`ToolbarSelect` is re-exported 1:1 from `@ui5/webcomponents-react/ToolbarSelect`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `Toolbar`; nest `ToolbarSelectOption`s.
