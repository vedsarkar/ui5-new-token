# Token

```tsx
import { Token } from "@reltio/design/components";
```

`Token` is a removable chip representing one selected value in a `MultiInput`.

`Token` is re-exported 1:1 from `@ui5/webcomponents-react/Token`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use in the `tokens` slot of `MultiInput`; set `text`.
