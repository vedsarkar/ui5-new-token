# ToolbarButton

`ToolbarButton` is an action button inside a `Toolbar`.

`ToolbarButton` is re-exported 1:1 from `@ui5/webcomponents-react/ToolbarButton`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `Toolbar`; set `text`, `icon`, `design`.
