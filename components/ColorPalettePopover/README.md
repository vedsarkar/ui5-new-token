# ColorPalettePopover

`ColorPalettePopover` opens a `ColorPalette` from a trigger for compact placements.

`ColorPalettePopover` is re-exported 1:1 from `@ui5/webcomponents-react/ColorPalettePopover`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Control with `open` + `opener`; compose `ColorPaletteItem` children.
