# TimelineItem

`TimelineItem` is one event on a `Timeline`.

`TimelineItem` is re-exported 1:1 from `@ui5/webcomponents-react/TimelineItem`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `Timeline`; set `titleText`, `subtitleText`, `icon`, `name`.
