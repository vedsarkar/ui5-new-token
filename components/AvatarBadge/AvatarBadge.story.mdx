# AvatarBadge

```tsx
import { AvatarBadge } from "@reltio/design/components";
```

`AvatarBadge` overlays a small status indicator on an `Avatar` — a presence dot, a verification check, an alert.

`AvatarBadge` is re-exported 1:1 from `@ui5/webcomponents-react/AvatarBadge`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Place it in the `badge` slot of an `Avatar`.
