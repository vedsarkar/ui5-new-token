# AvatarGroup

`AvatarGroup` displays a collection of `Avatar`s as an overlapping or grouped set, with overflow handling.

`AvatarGroup` is re-exported 1:1 from `@ui5/webcomponents-react/AvatarGroup`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Wrap multiple `Avatar` children; use `type` to switch between `Group` and `Individual` display.
