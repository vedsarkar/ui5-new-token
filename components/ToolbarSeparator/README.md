# ToolbarSeparator

`ToolbarSeparator` draws a vertical divider between groups in a `Toolbar`.

`ToolbarSeparator` is re-exported 1:1 from `@ui5/webcomponents-react/ToolbarSeparator`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Place between `Toolbar` items.
