# SegmentedButtonItem

`SegmentedButtonItem` is one option in a `SegmentedButton` group.

`SegmentedButtonItem` is re-exported 1:1 from `@ui5/webcomponents-react/SegmentedButtonItem`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `SegmentedButton`; set `selected` and label text.
