# CalendarLegend

`CalendarLegend` explains the color coding used by a `Calendar`'s special dates.

`CalendarLegend` is re-exported 1:1 from `@ui5/webcomponents-react/CalendarLegend`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Compose `CalendarLegendItem` children; bind to a `Calendar` via its legend.
