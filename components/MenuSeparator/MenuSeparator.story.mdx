# MenuSeparator

```tsx
import { MenuSeparator } from "@reltio/design/components";
```

`MenuSeparator` draws a divider between logical groups of `MenuItem`s.

`MenuSeparator` is re-exported 1:1 from `@ui5/webcomponents-react/MenuSeparator`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Place between `MenuItem`s inside a `Menu`.
