# MenuItem

`MenuItem` is a single action in a `Menu`, with optional icon and submenu.

`MenuItem` is re-exported 1:1 from `@ui5/webcomponents-react/MenuItem`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `Menu`; set `text`, `icon`, `additionalText`, or nest `MenuItem`s.
