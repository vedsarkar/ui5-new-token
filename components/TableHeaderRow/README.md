# TableHeaderRow

`TableHeaderRow` is the header row of a `Table`, holding `TableHeaderCell`s.

`TableHeaderRow` is re-exported 1:1 from `@ui5/webcomponents-react/TableHeaderRow`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Place in the `headerRow` slot of a `Table`.
