# TimelineGroupItem

`TimelineGroupItem` groups `TimelineItem`s under a heading on a `Timeline`.

`TimelineGroupItem` is re-exported 1:1 from `@ui5/webcomponents-react/TimelineGroupItem`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `Timeline`; set `titleText` and nest `TimelineItem`s.
