# SuggestionItemCustom

`SuggestionItemCustom` is an `Input` suggestion with fully custom content.

`SuggestionItemCustom` is re-exported 1:1 from `@ui5/webcomponents-react/SuggestionItemCustom`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `Input` with `showSuggestions` when a suggestion needs rich layout.
