# ComboBoxItemGroup

`ComboBoxItemGroup` groups related `ComboBoxItem`s under a header.

`ComboBoxItemGroup` is re-exported 1:1 from `@ui5/webcomponents-react/ComboBoxItemGroup`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `ComboBox`; set `headerText` and nest `ComboBoxItem`s.
