# SpecialCalendarDate

`SpecialCalendarDate` highlights a specific date in a `Calendar` (holiday, milestone, deadline).

`SpecialCalendarDate` is re-exported 1:1 from `@ui5/webcomponents-react/SpecialCalendarDate`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `Calendar`; set `value` and optionally a `type`.
