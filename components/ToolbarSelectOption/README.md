# ToolbarSelectOption

`ToolbarSelectOption` is one option in a `ToolbarSelect`.

`ToolbarSelectOption` is re-exported 1:1 from `@ui5/webcomponents-react/ToolbarSelectOption`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `ToolbarSelect`; set `selected` and label text.
