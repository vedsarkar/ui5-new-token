# NotificationListItem

`NotificationListItem` is one actionable notification in a `NotificationList`.

`NotificationListItem` is re-exported 1:1 from `@ui5/webcomponents-react/NotificationListItem`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `NotificationList`; set `titleText`, `state`, `importance`, `read`.
