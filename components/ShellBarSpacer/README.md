# ShellBarSpacer

`ShellBarSpacer` adds flexible space to push following `ShellBar` content to the end.

`ShellBarSpacer` is re-exported 1:1 from `@ui5/webcomponents-react/ShellBarSpacer`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Place between `ShellBar` content items.
