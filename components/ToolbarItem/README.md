# ToolbarItem

`ToolbarItem` wraps an arbitrary UI5 component so it participates in `Toolbar` overflow.

`ToolbarItem` is re-exported 1:1 from `@ui5/webcomponents-react/ToolbarItem`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `Toolbar`; wrap a control (e.g. `CheckBox`).
