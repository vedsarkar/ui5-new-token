# TableRowAction

`TableRowAction` is a per-row action button shown in a `TableRow`'s actions slot.

`TableRowAction` is re-exported 1:1 from `@ui5/webcomponents-react/TableRowAction`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Place in the `actions` slot of a `TableRow`; set `icon` and `text`.
