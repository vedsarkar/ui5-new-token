# ListItemGroup

`ListItemGroup` groups related list rows under a header inside a `List`.

`ListItemGroup` is re-exported 1:1 from `@ui5/webcomponents-react/ListItemGroup`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `List`; set `headerText` and nest `ListItem`s.
