# ComboBoxItem

`ComboBoxItem` is a selectable option in a `ComboBox`.

`ComboBoxItem` is re-exported 1:1 from `@ui5/webcomponents-react/ComboBoxItem`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `ComboBox`; set `text`.
