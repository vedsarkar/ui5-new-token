# OptionCustom

`OptionCustom` is a `Select` option whose content is fully custom (icons, rich layout).

`OptionCustom` is re-exported 1:1 from `@ui5/webcomponents-react/OptionCustom`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `Select` when an option needs more than plain text.
