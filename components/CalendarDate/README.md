# CalendarDate

`CalendarDate` marks a selected date inside a `Calendar`.

`CalendarDate` is re-exported 1:1 from `@ui5/webcomponents-react/CalendarDate`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `Calendar`; `value` follows the calendar's `formatPattern`.
