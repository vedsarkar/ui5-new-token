# TabSeparator

`TabSeparator` draws a divider between tabs in a `TabContainer`.

`TabSeparator` is re-exported 1:1 from `@ui5/webcomponents-react/TabSeparator`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Place between `Tab`s inside a `TabContainer`.
