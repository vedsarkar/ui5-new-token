# BreadcrumbsItem

`BreadcrumbsItem` is a single step in a `Breadcrumbs` trail, optionally a link via `href`.

`BreadcrumbsItem` is re-exported 1:1 from `@ui5/webcomponents-react/BreadcrumbsItem`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `Breadcrumbs`; the last item is the current page.
