# TableSelectionMulti

`TableSelectionMulti` enables multi-row selection in a `Table`.

`TableSelectionMulti` is re-exported 1:1 from `@ui5/webcomponents-react/TableSelectionMulti`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Place in the `features` slot of a `Table`.
