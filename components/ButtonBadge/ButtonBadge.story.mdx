# ButtonBadge

```tsx
import { ButtonBadge } from "@reltio/design/components";
```

`ButtonBadge` shows a count or status marker on a `Button` — unread items, pending actions.

`ButtonBadge` is re-exported 1:1 from `@ui5/webcomponents-react/ButtonBadge`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Place it in the `badge` slot of a `Button`; set `text` for a count.
