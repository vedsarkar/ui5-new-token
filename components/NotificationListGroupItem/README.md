# NotificationListGroupItem

`NotificationListGroupItem` is a collapsible group of notifications in a `NotificationList`.

`NotificationListGroupItem` is re-exported 1:1 from `@ui5/webcomponents-react/NotificationListGroupItem`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `NotificationList`; set `titleText` and nest `NotificationListItem`s.
