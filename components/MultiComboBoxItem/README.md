# MultiComboBoxItem

`MultiComboBoxItem` is a selectable, checkable option in a `MultiComboBox`.

`MultiComboBoxItem` is re-exported 1:1 from `@ui5/webcomponents-react/MultiComboBoxItem`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `MultiComboBox`; set `text` and optionally `selected`.
