# ShellBarSearch

`ShellBarSearch` is the search field used inside the `ShellBar`.

`ShellBarSearch` is re-exported 1:1 from `@ui5/webcomponents-react/ShellBarSearch`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Place in the `searchField` slot of the `ShellBar`.
