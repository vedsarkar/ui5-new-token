# Breadcrumbs

```tsx
import { Breadcrumbs } from "@reltio/design/components";
```

`Breadcrumbs` is the SAP Fiori breadcrumb trail, re-exported from `@ui5/webcomponents-react/Breadcrumbs` as the canonical Reltio entry point. Use it to show the user's location in a hierarchy and let them navigate back up — from a drilled-in entity to its list, from a sub-view to the parent screen. Compose the trail from `BreadcrumbsItem` children.

There is no Reltio wrapping or default override: the props, slots, and runtime behavior are exactly those of `@ui5/webcomponents-react/Breadcrumbs`. The Reltio layer adds curation, pinned versioning, and richer documentation.

### Composition

- Children are **`BreadcrumbsItem`** entries; each takes `href`/`target` for real navigation or is handled via the breadcrumbs' `onItemClick`.
- The **last item** is the current page. With `design="Standard"` (default) it renders as plain text; with `design="NoCurrentPage"` the trail ends at the parent and the current page is omitted.
- **`separators`** — the glyph between items (`Slash` default, `GreaterThan`, `BackSlash`, …).

Long trails automatically collapse overflow items into a dropdown.
