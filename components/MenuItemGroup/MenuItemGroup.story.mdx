# MenuItemGroup

```tsx
import { MenuItemGroup } from "@reltio/design/components";
```

`MenuItemGroup` groups `MenuItem`s with a selection mode (single/multiple).

`MenuItemGroup` is re-exported 1:1 from `@ui5/webcomponents-react/MenuItemGroup`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `Menu`; set `checkMode` and nest `MenuItem`s.
