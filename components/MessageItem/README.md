# MessageItem

`MessageItem` is one message (with severity) in a `MessageView`.

`MessageItem` is re-exported 1:1 from `@ui5/webcomponents-react/MessageItem`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `MessageView`; set `titleText`, `type`, `subtitleText`.
