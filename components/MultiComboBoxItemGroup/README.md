# MultiComboBoxItemGroup

`MultiComboBoxItemGroup` groups related `MultiComboBoxItem`s under a header.

`MultiComboBoxItemGroup` is re-exported 1:1 from `@ui5/webcomponents-react/MultiComboBoxItemGroup`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `MultiComboBox`; set `headerText`.
