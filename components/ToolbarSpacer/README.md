# ToolbarSpacer

`ToolbarSpacer` adds flexible space that pushes following `Toolbar` items to the end.

`ToolbarSpacer` is re-exported 1:1 from `@ui5/webcomponents-react/ToolbarSpacer`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Place between `Toolbar` items.
