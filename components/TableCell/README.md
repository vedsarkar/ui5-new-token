# TableCell

`TableCell` is a single cell in a `TableRow`.

`TableCell` is re-exported 1:1 from `@ui5/webcomponents-react/TableCell`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `TableRow`, one per column.
