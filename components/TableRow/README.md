# TableRow

`TableRow` is a data row in a `Table`, holding `TableCell`s.

`TableRow` is re-exported 1:1 from `@ui5/webcomponents-react/TableRow`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `Table`; set a unique `rowKey`.
