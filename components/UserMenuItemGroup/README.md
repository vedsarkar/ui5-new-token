# UserMenuItemGroup

`UserMenuItemGroup` groups items inside a `UserMenu`.

`UserMenuItemGroup` is re-exported 1:1 from `@ui5/webcomponents-react/UserMenuItemGroup`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use within a `UserMenu` to group related account/menu items.
