# Tab

`Tab` is one tab (header + content) in a `TabContainer`.

`Tab` is re-exported 1:1 from `@ui5/webcomponents-react/Tab`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `TabContainer`; set `text`, `icon`, `selected`.
