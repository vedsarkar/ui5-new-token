# Option

`Option` is a single choice in a `Select`.

`Option` is re-exported 1:1 from `@ui5/webcomponents-react/Option`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `Select`; set `value` and label text.
