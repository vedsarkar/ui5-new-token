# ShellBarBranding

```tsx
import { ShellBarBranding } from "@reltio/design/components";
```

`ShellBarBranding` renders the product brand mark/logo in the `ShellBar`.

`ShellBarBranding` is re-exported 1:1 from `@ui5/webcomponents-react/ShellBarBranding`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Place in the `branding` slot of the `ShellBar`.
