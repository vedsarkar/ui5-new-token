# MessageViewButton

`MessageViewButton` is a button showing the aggregate message count/severity that opens a `MessageView`.

`MessageViewButton` is re-exported 1:1 from `@ui5/webcomponents-react/MessageViewButton`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Place in a footer or toolbar; set `type` and `counter`.
