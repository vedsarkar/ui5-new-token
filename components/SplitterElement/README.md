# SplitterElement

`SplitterElement` is one resizable pane inside a `SplitterLayout`.

`SplitterElement` is re-exported 1:1 from `@ui5/webcomponents-react/SplitterElement`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `SplitterLayout`; set `size`, `minSize`, `resizable`.
