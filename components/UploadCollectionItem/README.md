# UploadCollectionItem

`UploadCollectionItem` is one file row in an `UploadCollection`.

`UploadCollectionItem` is re-exported 1:1 from `@ui5/webcomponents-react/UploadCollectionItem`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `UploadCollection`; set `fileName` and body metadata.
