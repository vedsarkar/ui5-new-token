# CalendarLegendItem

`CalendarLegendItem` is one entry in a `CalendarLegend`, pairing a label with a date type.

`CalendarLegendItem` is re-exported 1:1 from `@ui5/webcomponents-react/CalendarLegendItem`; its props, slots, and behavior are exactly the UI5 component's. The Reltio layer adds curation (the endorsed surface), pinned versioning, and documentation.

### Usage

Use as children of `CalendarLegend`; set `text` and optionally `type`.
