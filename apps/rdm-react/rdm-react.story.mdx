# RDM

> **Repository:** `reltio-ondemand/rdm-react`

RDM React is the Reference Data Management UI application for the Reltio platform. It provides a browser-based interface for managing lookup types, lookup values, source mappings, code generators, and autopilot monitoring. The application is served by a Node.js/Express backend that handles OAuth authentication, API proxying, configuration delivery, and activity logging.

## Application Structure

```
apps/rdm-react/src/
├── src/                        # Client-side React application
│   ├── app.tsx                 # Entry point — renders <Main /> into #rdm-app
│   ├── Main.tsx                # Root providers: Redux, MUI theme, feature flags
│   ├── AppComponent.tsx        # React Router configuration and top-level routes
│   ├── pages/                  # Page-level components (see Pages below)
│   ├── components/             # Shared UI components (AppBar, dialogs, tables, etc.)
│   ├── redux/                  # Actions, reducers, selectors, store, middlewares
│   ├── rdm-sdk/                # API client and domain model for the RDM service
│   ├── core/                   # Auth, utilities, Sentry initialisation
│   ├── configs/                # Runtime config loading and feature flag streams
│   └── themes/                 # MUI theme definition for RDM
└── server/                     # Node.js/Express server
    ├── app.ts                  # Express app: auth, static serving, proxies
    ├── middlewares/            # CSP, OAuth proxy, workflow, RDM API proxy, versioning
    ├── controllers/            # Config, translations, download endpoints
    └── utils/                  # Config manager, Vault integration, logging helpers
```

## Local Development

```bash
# Install dependencies
npm install

# Start the Webpack Dev Server (client only, proxies to a QA backend)
npm run qa      # sets NODE_CONFIG_DIR=./transitionConfig and NODE_ENV=qa
npm run wds     # starts Webpack Dev Server on http://localhost:3000

# Run tests
npm test

# Lint
npm run lint

# Production build
npm run build   # builds client bundle + server TypeScript + git-info
```

The server requires `clientSecret` in `transitionConfig/qa.json` and, optionally, `GOOGLE_APPLICATION_CREDENTIALS` for BigQuery activity logging.
