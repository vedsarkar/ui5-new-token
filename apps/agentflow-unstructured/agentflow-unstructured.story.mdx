# AgentFlow Unstructured

> **Repository:** `reltio-ondemand/agentflow-unstructured-frontend`

**AgentFlow Unstructured** (also referred to as **Unstructured Data Studio** in deployment and architecture docs) is the web UI for Reltio’s unstructured-data platform. It helps teams turn documents and enterprise content into structured, AI-ready insights: configure extraction pipelines, run batch document processing, and (in progress) build RAG-style knowledge workflows. The app is the customer-facing shell for **Document AI** today, with **Knowledge AI** (Context AI) and **Multimodal AI** on the product roadmap.

The frontend was migrated from Create React App to **Next.js 15 (Pages Router)** with a **custom Express server** that handles SSO, API proxying, and production hosting. It talks to a separate **Spring Boot** backend (`API_BASE_URL`, default `http://localhost:8080/api` in dev).

### Document AI — main features

- **Onboarding hub** — Guided three-step path: create template → configure sources → set up pipeline (`WelcomeScreen` with localStorage progress flags).
- **Template creation wizard** (`/createtemplate`) — Session-based flow: select document and target schema, **review extraction** (LLM output + PDF viewer), **verify mappings** (entities and field mappings), optional AI chat panel during review.
- **Template configs** (`/templates`) — List and resume draft templates; opens the creation wizard with an existing session.
- **Pipeline configs** (`/pipelineconfigs`, `/createnewpipeline`) — Define published pipelines tied to templates; cron scheduling and source binding.
- **Pipeline executions** (`/pipelineexecutions`, `/pipelineexecutions/[id]`) — Monitor batch runs, search/filter by pipeline, poll execution documents.
- **Sources** (`/sources`) — Configure document ingestion (cloud storage connectors; E2E covers GCS and related config).
- **Backend contract** — REST under <code>/document-ai/*</code> and batch APIs (e.g. <code>/v2/batch-runs/pipelines/{`{id}`}/start</code>); session artifacts stored server-side for resumable wizard state.

### Knowledge AI (Context AI) — in progress

- Routes under <code>/dashboard/context-ai/*</code>: RAG config, search indexes, conversations (feature modules in <code>src/features/context-ai/</code>).
- **RAG demo** (`/rag-demo`) — Upload → index configuration → indexing progress → grounded chat with citations.

## Key patterns

**Express + Next hybrid** — <code>npm run dev</code> runs <code>server/index.ts</code>, which prepares Next.js and mounts SSO, health (<code>GET /health</code>), version metadata, PDF.js worker static assets, and a reverse proxy from <code>/api/*</code> to the Java backend.

**Authentication** — <code>auth-middleware</code> on <code>/auth</code> (login, callback, logout, status, present). Access tokens in HTTP-only cookies; failed product authorization shows an inline “access denied” gate in <code>Layout</code>.

**Session-based Document AI wizard** — Template creation uses server-side <code>pipeline_sessions</code> (create/resume/abandon via API); the UI stores <code>createtemplate_sessionId</code> in <code>sessionStorage</code> across steps.

**Permission gates** — <code>useCapabilities</code> / <code>PermissionGate</code> hide or disable nav sections based on OAuth capabilities for the AFU service.

**Design system** — RDS3 primitives and theme CSS (<code>src/RDS3/</code>) plus MUI theming (<code>ThemeContext</code>); AgentFlow branding components. This app is a **migration candidate** for SAP Fiori via <code>@reltio/design</code> but does not consume it today.
