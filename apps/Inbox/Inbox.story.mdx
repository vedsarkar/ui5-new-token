# Inbox Overview

Inbox is the centralized hub to view and manage workflow tasks assigned to you and your team.

Use the Reltio Inbox to view workflow tasks generated for a user, and then perform the corresponding action required for the task.

### Inbox anatomy

Use the following key areas of the Inbox page to view your Inbox tasks.

<img src="./inbox-anatomy.png" alt="Inbox anatomy" />

### A. Select workflow task tab
By default, your open assigned tasks are in view. In the navigation menu on the left, you may select:
* Inbox (My assigned tasks) - this is the default view with Filters > Status = Open
* Team (All team tasks) - tasks assigned to your team. Team members can action or view any of these tasks.
* Sent (My requested tasks) - tasks that you sent for approval.
* All (All tasks) - no filters, both open and closed tasks. The users who have the necessary permissions are able to access the closed or resolved tasks. By default, closed tasks are available in the Inbox for a period of one year from the resolved or closed date.
All (All tasks) - no filters, both open and closed tasks. The users who have the necessary permissions are able to access the closed or resolved tasks. By default, closed tasks are available in the Inbox for a period of one year from the resolved or closed date.

### B. Filters
Use the filters in the navigation menu to narrow down tasks by these criteria: Task type, Step, DCR type, Entity type, Relationship type, Priority, Status, Step action taken, Created by, Created date, Assigned to, Entity ID, DCR ID, Decision, and Has Changes. For more information, see topic Filter tasks.

### C. Tasks selector
Select all or clear selected tasks.

### D. Task type tabs
Select the type of task to view:
* ALL - default
* AUTHORING - tasks for authoring entities.
* DATA CHANGE REQUEST REVIEW - tasks to change entities.
* POTENTIAL MATCH REVIEW - tasks that involve a potential match.
* RDM DATA CHANGE REQUEST REVIEW - tasks to change reference data.
* RECOMMEND FOR DELETE - tasks with data deletion recommendations.

### E. Column selector & View switcher
Using show/hide columns, select the columns to view for the tasks: Task type, Entities, Status, Priority, Created by, Created on, Taken on, and Action taken.

The View switcher switches the display of task details between list and tabular format. For more information, see topic Switch between Table and List views.

### F. Workflow task details area
The area to the right of the navigation pane displays the tasks according to the selections and filters. The task icon indicates the process the task belongs to. More than one process can be represented in the list, and the processes can be varied with regard to things like approving an expense report, matching tasks, and so on.
