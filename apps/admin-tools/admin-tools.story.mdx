# Admin Tools

> **Repository:** `reltio-ondemand/admin-tools`

Admin Tools is a Next.js web application that provides Reltio platform administrators with a centralized interface for managing tenants, users, configurations, integrations, and data pipelines. It runs as a full-stack app with an Express server layer handling proxying and authentication middleware, and a Next.js frontend serving the admin UI.

## Tech Stack

- **Framework:** Next.js 15 (React 18)
- **UI Library:** MUI (Material UI) v5 with Emotion
- **State Management:** MobX (mobx-react-lite)
- **Styling:** CSS Modules + MUI Emotion-based styling
- **Charts:** Recharts
- **Language:** TypeScript
- **Testing:** Playwright (integration), with nyc coverage
- **Server:** Express (custom SSR/proxy server, compiled separately via `tsc`)

## Application Structure

The app follows a **Next.js pages-based routing** structure with a parallel `apps/` directory containing feature-specific sub-apps that each bundle their own components, pages, and utilities. The top-level `pages/` directory wires Next.js routes to these sub-app implementations.
