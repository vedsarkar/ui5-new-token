# Inbox

> **Repository:** `reltio-ondemand/workflow-ui`

Workflow UI (also known as Inbox) is a React 17 single-page application that provides Reltio users with a task management interface for reviewing and acting on workflow tasks generated by the Reltio platform. It serves as the primary UI for stewardship workflows — enabling users to process potential match reviews, data change requests (DCRs), delete reviews, and authoring tasks assigned to them or their team.

## Tech Stack

- **Framework:** React 17 with class-based components
- **UI Library:** MUI (Material UI) v5 with Emotion
- **State Management:** Redux (redux-thunk, redux-promise-middleware)
- **Data Fetching:** TanStack React Query v4 + Axios with retry
- **Drag and Drop:** react-dnd v13
- **Routing:** React Router v5
- **Styling:** LESS modules + CSS
- **Internationalization:** ui-i18n (internal Reltio package)
- **Language:** JavaScript (ESLint, Babel)
- **Testing:** Jest + Enzyme + React Testing Library (unit), Playwright (integration)
- **Server:** Express (Node.js BFF — handles auth, proxying, CSP, config, and Vault-based secrets)
- **Build:** Webpack 5 (client), Babel (server), Gulp (icons, i18n, readme)
- **Error Tracking:** Sentry

## Application Structure

The app follows a **client + BFF (Backend for Frontend) architecture**. The Express server in `server/` handles authentication, proxying requests to downstream Reltio services, and serving the compiled client bundle. The React client in `src/` implements the task management UI with a Redux store.

## Infrastructure

The app is containerized (Dockerfile in `devops/`) and deployed via Helm charts with Istio virtual service configuration. It integrates with HashiCorp Vault for secret injection at runtime and supports horizontal pod autoscaling. The default port is `8080`.
