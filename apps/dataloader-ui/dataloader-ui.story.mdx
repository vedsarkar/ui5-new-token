# Dataloader UI

> **Repository:** `reltio-ondemand/dataloader-ui`

Dataloader UI is a React web application that lets Reltio users upload and manage batch data ingestion jobs for a selected tenant. Users configure load projects with field mapping rules, submit jobs from multiple storage sources, and track job history — all through a guided wizard and dashboard interface.

## Key Features

### Projects

The **Projects** page (`/projects`) lists all saved load configurations. Each project stores:

- target entity type or relation type
- load mode (insert, update, full update)
- field mapping from source columns to Reltio attributes
- selected data source and credential reference

Projects are created and edited through the **Project Wizard**, a four-step flow:

1. **Define Project** — set name, entity/relation type, and load mode
2. **Upload Data** — choose a data source (local file, Amazon S3, Azure Blob, Google Cloud Storage, SFTP, or device upload) and provide credentials
3. **Mapping** — drag source columns onto target Reltio attributes; supports simple, nested, multiple-nested attributes, crosswalks, and relation member objects
4. **Review** — verify configuration and submit the load job

### Jobs

The **Jobs** page (`/jobs`) shows all submitted jobs with status, duration, and record counts. Clicking a completed job opens a detailed review with processing statistics and error analysis.

### Settings

The **Settings** page (`/settings`) manages reusable storage credentials for Amazon S3, Azure Blob Storage, Google Cloud Storage, and SFTP — referenced by projects at upload time.

## Running Locally

```bash
# Install dependencies
npm install --legacy-peer-deps

# Start development server (with hot reload)
npm run start-dev

# Build for production
npm run build

# Run unit tests
npm test

# Run E2E tests (requires a running app instance)
npx playwright test
```
