# Data Out

> **Repository:** `reltio-ondemand/data-out`

Data Out is a Next.js 15 application that manages Reltio Data Share — the outbound adapter configuration UI for exporting Reltio data to Snowflake, Databricks, and Microsoft Fabric. It is extracted from `admin-tools` and runs as a Next.js multi-zone target behind it: admin-tools owns the surrounding shell and shared APIs, while this app serves all pages under the `/data-out` URL prefix.

## Multi-Zone Integration

Data Out runs as a Next.js [multi-zone](https://nextjs.org/docs/app/building-your-application/deploying/multi-zones) child alongside admin-tools:

- **URL prefix**: pages live under `pages/data-out/...` so all routes already start with `/data-out`; no Next.js `basePath` is set.
- **Asset prefix**: `/data-out-static` keeps static chunk URLs distinct from admin-tools'.
- **admin-tools rewrites** (post RP-180412 merge): two rewrites forward `/data-out-static/_next/*` (static assets) and `/data-out/*` (pages) to this app via the `DATA_OUT_URL` env var (default `http://localhost:3001`).
- **Shared APIs** (`/api/auth/*`, `/api/tenants`, `/api/adminToolsConfig`, `/api/nodeConfig`, `/api/config/*`, `/api/physicalConfig/*`, `/api/core/*`, `/api/proxy/*`) and the `/data-out/data-pipelines` route remain in admin-tools and are not served by this app.

## Development

```bash
nvm use          # Node v22.22.0
npm ci
npm run dev      # http://localhost:3001/data-out/data-share
```

Run alongside admin-tools (port 8080) for end-to-end flows that need shared APIs or the `/data-out/data-pipelines` page. Hitting port 3001 directly is sufficient for Data Share UI rendering and Playwright tests.

## Testing

```bash
npx playwright install --with-deps   # First time only
npm run test                         # Headless Chromium
npm run test:ui                      # Interactive Playwright UI
```

Test files live in `tests/`, use the `data-test-id` attribute, and rely on mock fixtures in `api-json/`.
