# HUB UI

> **Repository:** `reltio-ondemand/reltio-react-ui`

Reltio React UI is the main Reltio web application — a full-stack, tenant-aware React SPA backed by an Express.js server. It serves as the primary product interface for data stewardship, search, entity management, and AI-assisted workflows across all Reltio tenants.

└── server/                     # Express.js server

    ├── uiConfiguration/        # UI config loading (local / git / configService providers)

    ├── permissions/            # Role-based access control
    ├── proxy/                  # Reverse proxy to Reltio API and platform services
    ├── history/                # AI conversation history (in-memory + BigQuery)
    ├── conversationsService/   # Chat conversation management
    ├── exportDQ/               # Data quality export
    └── maps/                   # Google Maps service integration

## Server Architecture

The Express server sits in front of both the React SPA and all Reltio platform APIs. It handles:

- **Authentication** — OAuth token validation and cookie-based session management via `auth-middleware`
- **Reverse proxy** — Routes <code>/reltioAPI</code>, <code>/export</code>, <code>/workflow</code>, <code>/collaboration</code>, <code>/agentFlow</code>, and other paths to their respective backend services
- **UI configuration** — Serves tenant-specific UI configuration from one of three providers: `local` (filesystem), `git` (repository clone), or `configService` (config-service API)
- **AI orchestration** — <code>/services/ai</code> endpoint that routes natural-language input to an intent classifier (NLP search, chart generation, export, profile summary, proxy), each backed by an OpenAI or Azure OpenAI provider
- **Client config** — <code>/clientConfig</code> endpoint that injects runtime paths and keys into the SPA at startup
- **Security** — Content Security Policy (CSP) headers computed per-tenant from the active UI config

## Development

```bash
# Install dependencies
npm install

# Start both server and client in development mode
npm start

# Build for production
npm run build

# Run unit tests
npm test

# Run E2E healthcheck tests
npx playwright test health.spec.ts

# Run UI config dry-run E2E tests
npx playwright test dryRun.spec.ts

# Download environment properties
npm run get-env-properties <environment>
```
