# External Match UI

> **Repository:** `reltio-ondemand/external-match-ui`

External Match UI is a Next.js web application that allows data stewards to run external match jobs against Reltio tenants by uploading CSV files or pointing to cloud storage locations (AWS S3, GCP, SFTP). It provides a wizard-driven workflow for defining jobs, mapping source columns to entity type attributes and match groups, and monitoring job execution status.

## Tech Stack

- **Framework:** Next.js 15 (React 18)
- **UI Library:** MUI (Material UI) v5 with Emotion
- **State Management:** Custom context-based app state using Immutable.js
- **Styling:** MUI Emotion-based styling (`withStyles`, `makeStyles`)
- **Language:** JavaScript (ES2017+)
- **Testing:** Jest + Enzyme
- **Server:** Express with custom OAuth middleware (`auth-middleware`, `node-oauth-provider`)
- **Error Monitoring:** Sentry (`@sentry/browser`)

## Application Structure

The app uses a **Next.js pages-based routing** structure with a clear client/server split. The Express server handles authentication, proxying to the Reltio External Match API, and operational endpoints. The Next.js frontend serves the job management UI.

## Configuration

The app uses the Node.js `config` module. Configuration files live in `src/config/`. Key properties:

<table>
  <thead>
    <tr>
      <th>Property</th>
      <th>Description</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td><code>clientId</code></td>
      <td>OAuth client ID for basic authorization.</td>
    </tr>
    <tr>
      <td><code>clientSecret</code></td>
      <td>OAuth client secret used for authorization and data encryption.</td>
    </tr>
    <tr>
      <td><code>urlPrefix</code></td>
      <td>URL path prefix prepended to all routes (default: <code>/externalMatch</code>).</td>
    </tr>
    <tr>
      <td><code>port</code></td>
      <td>HTTP server port (default: <code>8080</code>).</td>
    </tr>
    <tr>
      <td><code>paths.externalMatchApi</code></td>
      <td>Base URL of the Reltio External Match API that the server proxies to.</td>
    </tr>
    <tr>
      <td><code>paths.api</code></td>
      <td>Reltio platform API path. The <code>{`{environment}`}</code> variable is resolved from the admin tools config.</td>
    </tr>
    <tr>
      <td><code>paths.oauth</code></td>
      <td>Reltio OAuth service path.</td>
    </tr>
    <tr>
      <td><code>paths.adminToolsConfig</code></td>
      <td>Path to the admin tools configuration file used to resolve available environments.</td>
    </tr>
  </tbody>
</table>

## Local Development

```bash
npm install
npm run dev     # Starts the app at http://localhost:8080/externalMatch
```

To run tests:

```bash
npm test                # All tests
npm run test:client     # Client-side tests only
npm run test:server     # Server-side tests only
npm run test:coverage   # With coverage report
```
