# Workflow Modeler

> **Repository:** `reltio-ondemand/bpmn-modeler`

BPMN Modeler is a full-stack Reltio web application that allows users to create, edit, and manage business process definitions using the BPMN 2.0 standard. It wraps the `bpmn-js` library with an Activiti-compatible properties panel and exposes process definition management against the Reltio Workflow API. The application is served at `/bpmnmodeler` by a Node.js/Express backend that handles authentication, tenant access validation, and API proxying.

## Tech Stack

- **Framework:** React 17 with React Router v5
- **UI Library:** MUI v5 (Material UI) and `@reltio/components`
- **BPMN Engine:** `bpmn-js` 15.1.3 with `bpmn-js-properties-panel` and Activiti moddleExtensions
- **Server:** Node.js / Express with `auth-middleware` for OAuth token validation
- **Data Fetching:** TanStack React Query v4, Axios
- **State Management:** React Context API (`AppProvider`) + class-based `Modeler` service
- **Styling:** Less (`.less` files), `classnames` utility
- **Language:** TypeScript (client and server), Babel for client bundling
- **Build:** Webpack 5 (client), `tsc` (server)
- **Testing:** Jest + Enzyme (unit), Playwright (e2e)
- **Error Tracking:** Sentry

## Application Structure

The codebase is split into a `client/` and a `server/` directory.

**Client (`client/`)**

- `App.tsx` — Root component. Composes `AppBar`, `Sidebar`, `AccessChecker`, global dialogs/snackbar, and the route tree.
- `context/` — `AppProvider` holds global app state; `Modeler.tsx` is a class that wraps the `bpmn-js` modeler instance (import, export, dirty tracking, zoom, SVG export).
- `pages/` — Two main pages:
  - `ProcessDefinitionsPage` — lists saved process definitions, supports create/open/delete/download.
  - `ProcessDefinitionContent` — hosts the BPMN canvas editor for a single process definition.
- `components/` — Shared UI components: `Editor` (canvas + properties panel mount point), `Toolbar`, `Sidebar`, `AppBar`, `AppDialog`, `AppSnackbar`, `AccessChecker`, table renderers, and others.
- `services/` — Browser history and other client-side service utilities.
- `utils/bpmn-activiti/` — Activiti descriptor JSON, BPMN override JSON, default diagram XML, and a custom `PropertiesProvider`.

**Server (`server/`)**

- `app.ts` — Express app configuration with CSP, auth middleware, request signing, and tenant access validation.
- `services/` — Route handlers split into `public/` (healthcheck, status) and `secured/` (config, registrations, system config, version).
- `services/proxy/` — Transparent proxy to the Reltio Workflow API.
- `middlewares/` — Auth error handling, token checking, config service, namespace validation, and tenant access control.
- `utils/` — Auth helpers, workflow API path resolution, tenant–workflow adapter mapping, Vault config parsing, and logging.

**JAR Files (`pages/JarFilesPage/`)**

A secondary section of the app manages Activiti JAR file deployments — listing available JARs, deployed JARs, and supporting deploy/undeploy workflows via the Reltio API.
