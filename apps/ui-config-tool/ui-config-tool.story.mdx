# UI Modeler

> **Repository:** `reltio-ondemand/ui-config-tool`

UI Config Tool (branded as **UI Modeler**) is a full-stack web application for managing and publishing Reltio tenant UI configurations. It provides a visual authoring environment where administrators can edit profile layouts, dashboard widgets, and inline-editing settings per tenant and environment, then publish the resulting JSON configuration to a backing repository.

## Repository Providers

The server stores UI configuration through a pluggable repository layer. The active provider is set via `repoType` in `config/default.properties`.

## Key Features

- **Publish workflow** — edits are validated client-side before being written back to the configured repository; the Publish button is gated by the `canUpdateConfig` permission check.
- **Import wizard** — multi-step flow that lets administrators upload a configuration file, review a virtualized diff against the current version, and confirm the replacement.
- **Tenant switcher** — the `TenantSelector` shell component allows switching between tenants and environments without leaving the tool.
- **Feature flags** — a `FeatureProvider` context wraps the entire app; individual features (e.g. `inlineEditing`, `dashboard`, `newProfile`) are toggled via server-side config.
- **Config migration alerts** — surfaces in-app alerts with progress dialogs when a configuration schema migration is required.

## Local Development

```bash
# Install dependencies
npm install

# Start client (Webpack dev server) and server (Node.js) concurrently
npm start
```

Configure `gitPublicKey`, `gitPrivateKey`, and `configService.*` credentials in `config/default.properties` before starting. See the [README](apps/ui-config-tool/src/README.md) for full prerequisites (including WSL2 setup on Windows).
