# Segmentation Overview

Segmentation is the process of dividing large datasets into distinct groups based on shared characteristics or behaviors. The Hub’s Dynamic Segmentation feature provides the tools to perform this process on real-time master data. Its strategic value is immense, enabling organizations to tailor marketing strategies, personalize user experiences, and conduct more effective analysis by targeting specific, well-defined audience segments.

### Managing Segments

The main Segmentation page serves as the central console for this capability. Here, users can view a list of all existing segments and create new ones. For each segment, the interface displays key information at a glance, including its name, its status (e.g., Live, Computing), the total audience count, and the configured downstream destinations for activation, managing the entire lifecycle from creation to deployment.

These advanced modules showcase how the Hub extends beyond traditional MDM into a platform for strategic data utilization.
