# Dashboard Overview

In modern data management, dashboards are indispensable tools that provide at-a-glance visibility into the health and performance of an organization's data assets. The Reltio Hub's dashboards serve this exact purpose, offering real-time operational metrics and comprehensive data quality insights. They empower users to move from a reactive to a proactive data governance posture by making key performance indicators immediately accessible and easy to interpret.

### Purpose and Value

The Profile Stats dashboard offers a "bird's eye view" of the data within a Reltio tenant. It is designed to help users, from Data Stewards to System Administrators, visualize operational statistics and gather data insights to make quick business decisions. This dashboard acts as a central hub for monitoring activities such as profile updates, merges, and user actions over time.

Key Visualizations

The dashboard is composed of various charts, or facets, that visualize different aspects of the tenant's data. These visualizations fall into two main categories:

* Preconfigured Charts: The Hub comes with default charts, such as the Activity Log (displaying user activity) and the Notification Inbox (showing workflow task details), which are available out of the box.
* General Chart Formats: A wide variety of chart types can be configured to display business-specific data, including Bar, Line, Map, Donut, and Pie charts. These can be used to represent everything from tenant operational statistics to business data visualizations on a map.

### User Personalization

A key feature of the Profile Stats dashboard is its high degree of customizability. While administrators can configure a default layout for all users, each individual user can personalize their own dashboard view without affecting others. Users have the ability to add, remove, resize, and rearrange charts on their screen to create a layout that best suits their specific roles and preferences.
