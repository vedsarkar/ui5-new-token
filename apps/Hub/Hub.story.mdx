# Reltio Hub UI Overview

The Reltio Hub is the primary user interface for managing and interacting with data within the Reltio Data Cloud. It is the home page and central workspace where users access the full suite of tools needed to search, view, manage, and analyze the unified data profiles that form the core of their master data repository.

The Hub is purpose-built to empower users to maintain and leverage high-quality, trusted data. Its core value is delivered through a set of integrated capabilities that allow users to:

* View and manage unified data records: Access a consolidated, 360-degree view of any entity, complete with all its attributes and relationships.
* Monitor and improve data integrity: Utilize dashboards with key data quality metrics to proactively identify and address issues, ensuring the overall health of the data.
* Search, create, update, and delete profiles: Perform essential data lifecycle management tasks to keep records accurate, complete, and up to date.
* Resolve potential data duplicates: Efficiently review potential matches to merge redundant records, maintaining a single, consistent, and authoritative view of each entity.
* Explore relationships between data profiles: Investigate the connections and hierarchies between different entities to uncover deeper insights and understand complex data networks.

### Primary User Roles

The Reltio Hub is designed to serve a diverse set of users across the organization, each with a distinct role in the data management lifecycle. Key user personas include:

* Data Steward: Responsible for day-to-day data governance, quality, and stewardship tasks, such as resolving potential matches and ensuring data accuracy.
* Business User: Leverages the Hub to access clean, reliable data for operational tasks and decision-making without needing deep technical expertise.
* Data Analyst: Explores and analyzes master data to identify trends, generate reports, and gain business insights.
* System Administrator: Configures and customizes the Hub environment, including dashboards and user roles, to meet the organization's needs.
* Data Product Owner: Oversees the strategy and use of master data assets, using the Hub to monitor data health and business value.

This application provides a comprehensive set of features, organized within a clear navigational structure to support these varied user needs.

## Core Navigation

A consistent and intuitive navigational framework is essential for any application that manages complex data, as it allows users to perform their tasks efficiently and discover new capabilities with ease. The Reltio Hub is organized around a clear and logical structure designed to provide quick access to its wide range of features, from high-level dashboards to granular data management tools.

### The Main Interface Layout

The Hub's main user interface is composed of two primary navigational components that remain persistent throughout the user's session:

* Header/Banner: Located at the top of the screen, this area displays the Reltio logo, the name of the current tenant, a global search bar for quick profile lookups, and global filters.
* Left Navigation Drawer: The Hub’s primary menu, organizing the platform's core functional modules into a persistent, accessible structure.

### Product-Specific Variations

It is critical to understand that the features and modules available in the Left Navigation Drawer are contingent on an organization's specific Reltio product subscription. The user experience is tailored to the functionality included with Reltio Entity Resolution, Reltio Multidomain MDM, or Reltio Intelligent 360, ensuring that users see only the tools relevant to their licensed capabilities.
