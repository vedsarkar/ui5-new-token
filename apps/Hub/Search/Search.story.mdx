# Search Overview

Search is the primary mechanism for unlocking the value within the Reltio Data Cloud. It's the gateway through which users move from searching for a record to discovering a new business insight. The Reltio Hub's Search module is a sophisticated tool designed to help users efficiently locate, filter, and explore specific data profiles, catering to a range of needs from simple lookups to the construction of complex, multi-faceted queries.

### Search Anatomy

### A. Left panel
This panel contains the following features:
* Advanced search - An extension of the Search feature that allows you to build complex queries to search for records. For more information, see topic Exploring the Advanced Search.
* Quick filters - A quick way to filter your record, this section lists the Entity types and their attributes. Select the entity type and the attribute values, and the entity records are filtered and displayed in the central panel.

### B. Top panel
This panel contains the following options:
* Load data - Select this option to launch the Data Loader application.
* Save - Select this option to save your search.
* Share link - Select this option to share your search results. When you select this option, a shareable link is displayed. Click COPY LINK to copy the link and share the search results URL.
* Saved and Recent Searches - Select this option to view a list of Saved and recent searches.

### C. Central panel
This panel displays the search results, based on your search criteria. You can also:
* View these results in the Table or List view.
* Use the View Map option to display the locations of the profiles. Profile locations are displayed as pin drops in the map. You can use the Search as I move and Polygon Search features to move the map around, or, draw a polygon; and your search results are displayed based on the map in real-time.
* Select View entity details option to view entity details.

### Core Search Methodologies

The Hub provides two primary methods for searching data, each suited to different strategic purposes.

* Quick Filters: This method is for exploratory analysis and rapid discovery. It offers a fast, facet-based approach to filtering records, ideal for answering questions like, "What's the general shape of our customer data in California?" The left-hand panel displays entity types and key attributes suggested by a machine learning-based recommendation engine, allowing users to instantly narrow down results and understand data distributions.
* Advanced Search: This method is for prescriptive segmentation and operational tasks. A sophisticated query builder, it is designed for constructing precise, complex searches to answer questions like, "Find all high-value customers in California with a missing email address for a targeted data enrichment campaign." Its key capabilities include using a wide range of operators (e.g., equals, exists, contains, in file, is pinned exists), selecting from all available attributes, and grouping criteria with AND/OR logic to create highly specific data segments.

### Managing and Visualizing Results

Once a search is executed, the Hub offers several features for interpreting and managing the results.

* Results Display: The central panel displays the search results, which can be toggled between two formats: a configurable Table view that is ideal for comparing multiple attributes across profiles, and a scannable List view for quickly browsing records.
* Map View: For profiles that contain geographic data, the Map View provides an interactive visualization of their locations as pins on a map. This feature includes powerful interactive tools like "Search as I move the map" and "Polygon Search," which allow users to dynamically filter results by exploring different geographic areas or drawing a specific boundary on the map.
* Saved & Recent Searches: To enhance efficiency and collaboration, users can save complex search queries for later reuse. The Hub also maintains a history of recent searches, allowing users to quickly access and re-run past queries. This is particularly valuable for recurring data analysis or stewardship tasks.

After locating the right profiles through search, the next step is to perform a deep-dive analysis on an individual record using the comprehensive Profile screen.
