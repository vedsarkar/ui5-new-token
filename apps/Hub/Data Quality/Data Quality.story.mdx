# Data Quality Overview

The Data Quality dashboard provides comprehensive, real-time insights into the consistency, accuracy, and completeness of the data. It is primarily targeted at Data Stewards and Data Analysts who are responsible for maintaining superior data quality. With over a dozen available charts, this dashboard gives a complete, up-to-date picture of data health, enabling users to identify and address quality issues proactively.

Dashboard Anatomy

The layout of the Data Quality dashboard is organized into three distinct areas to facilitate intuitive data exploration:

1. Entity Type Bar: Located at the top, this bar allows a user to select a specific entity type (e.g., Contact, Organization) from a dropdown list to focus the entire dashboard on that particular dataset.
2. Central Area: This is the main body of the dashboard, displaying a variety of data quality charts and metrics for the selected entity type. These charts provide insights into aspects like source system contributions, consolidation rates, and profiles with invalid data.
3. Attribute Panel: Positioned on the right side, this panel lists all attributes for the selected entity type. It provides options to search, filter, and select specific attributes, which in turn updates the charts in the central area to visualize quality metrics for those attributes.

These high-level dashboard views provide the essential top-down perspective on data health. An insight uncovered here—such as a high number of profiles with invalid addresses—can be the starting point of a targeted stewardship workflow, beginning with the Search module.
