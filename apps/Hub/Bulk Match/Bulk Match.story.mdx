# Bulk Match Overview

Managing data duplication is a persistent challenge for any organization striving for a single source of truth. Reviewing potential matches one profile at a time is a bottleneck when dealing with large datasets. The Reltio Hub's Bulk Match Review module is the solution designed for efficient, at-scale resolution of potential matches, allowing organizations to dramatically accelerate data cleansing. This directly impacts downstream analytics accuracy, marketing campaign ROI, and operational efficiency by eliminating costly errors caused by duplicate records.

### Bulk Match Anatomy

<img src="./bulk-match-anatomy.png" alt="Bulk Match Review anatomy" />

The core function of the Bulk Match Review module is to empower Data Stewards to review and resolve potential duplicate records in batches. The module allows stewards to load and review up to 100 potential match pairs in a single focused session. From this list, they can select and apply bulk actions—MERGE ALL or NOT A MATCH—to batches of up to 25 pairs at a time, dramatically accelerating resolution, reducing stewardship backlogs, and enhancing overall data quality.

### Core Workflow and Interface

The module provides a streamlined interface focused on rapid review and action.

Review and Action

The user begins by selecting an entity type (e.g., Individual, Organization). The main screen then displays a grid of potential match pairs identified by the system. From this grid, the data steward can select the checkboxes for multiple pairs and apply a bulk action with a single click: MERGE ALL, which merges the selected pairs, or NOT A MATCH, which dismisses the suggestions.

Filtering and Refinement

To help data stewards focus their efforts, the module includes powerful filtering capabilities. A quick filters panel on the left side allows users to narrow down the list of potential matches based on specific attribute values. Additionally, other options, such as the Show only OV (Operational Value) filter, can be used to display only the surviving attribute values determined by survivorship rules, simplifying the review process.

After addressing data quality at scale, users can turn to other advanced modules in the Hub to structure and analyze their data for broader business initiatives.
