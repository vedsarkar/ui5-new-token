# Tenant Management Overview

Tenant Management is a Console application that allows you to view tenant statistics, execute tenant management jobs, and monitor internal and external queues. The application provides comprehensive tools for analyzing match rules performance, monitoring queue sizes, managing jobs, and configuring tenant settings.

**Note:** Access permissions vary by feature. Some features require ROLE_API permissions to view, while others require ROLE_ADMIN_TENANT permissions to edit.

## Accessing Tenant Management

To access Tenant Management:

1. In the Reltio Console, select **Tenant Management** from the applications menu
2. Click the **Select Tenant** button to choose the tenant you want to manage
3. Use the left navigation sidebar to access different sections:
   * **MONITORING** - Statistics, Match analysis, Queues
   * **MANAGE** - Jobs, External queues, Tenant Configuration

## Match Analysis

<img src="/tenant-management/screen-1.png" alt="Tenant Management - Match Analysis summary page" />

Match Analysis helps you analyze the generation of match token phrases and the performance of match rules configured in your tenant. The number of match token phrases generated has a direct impact on the performance of a match rule.

### Match Analysis Summary

The Match Analysis page provides a summary view with three main tabs:

1. **SUMMARY** - Overview of all analysis results (default view)
2. **MATCH TOKEN PHRASES** - Detailed analysis of token phrase distribution
3. **MATCH RULES** - Analysis of match rules performance
4. **MATCH PRECISION** - Measures the accuracy of match rules based on reviewed matches

**Summary Results Display:**

* **Match token phrases analysis** - Reviews the distribution of token phrases generated:
  * Distribution of token phrases generated
  * Percentage of entities that generated less than 300 token phrases
  * Percentage of entities that generated over 5 token phrases
  * Average number of token phrases per entity across all match groups

* **Match rules analysis** - Reviews the number of match pairs generated:
  * Distribution of match pairs generated
  * Whether match rules are creating an expected number of matched outcomes
  * Least frequently used match rules
  * Whether all match groups are participating in the matching process
  * Overlap of match results by rule pairs
  * Distribution of match group tactics

* **Match precision score** - Measures the accuracy of match rules:
  * Overall precision percentage
  * Change from previous analysis date
  * Visual representation of precision trends

**Key Features:**
* **Entity Type Filtering** - View results filtered by entity type (e.g., HCP, HCO, Title)
* **Match Rule Filtering** - Filter results by specific match rules
* **RUN ANALYSIS Button** - Located in the upper-right corner, allows you to launch a new Analyze Match Strategy job. The date displayed next to this button shows when the job was last run
* **VIEW DETAILS Links** - Click to drill down into detailed analysis for each section
* **Entity Type Expansion** - Click the down arrow next to entity types to view entity-specific summaries

**Analysis Checks:**

The Analyze Match Rules job checks for:
* **Too many tokens** - If too many tokens are generated by a subset of processed entities than the specified threshold
* **Too few tokens** - If too few tokens are generated by a subset of processed entities than the specified threshold
* **Match pairs** - The number of match pairs generated for the specified set of entities

**Use Cases:**
* Improve your tokenization scheme
* Tune your match rules to ensure matching produces desired results
* Identify performance bottlenecks in match rule processing
* Monitor match rule effectiveness over time

## Queues Monitoring

<img src="/tenant-management/screen-2.png" alt="Tenant Management - Queues monitoring page" />

The Queues page provides real-time monitoring of internal queue sizes to help you track system performance and identify potential bottlenecks.

### Queue Size Monitoring

**Queue Types:**
* **CRUD Queue** - Tracks Create, Read, Update, Delete operations
* **Match Queue** - Tracks match processing operations

**Monitoring Features:**
* **Queue Size Graph** - Visual representation of queue sizes over time:
  * Line graph showing queue size trends
  * Current queue size for each queue type
  * Average queue size for the selected time range
  * Color-coded lines for different queue types (e.g., light blue for CRUD, orange for Match)

* **Filters:**
  * **Queue type** - Filter by Internal or External queues
  * **Time range** - Select time period (e.g., Last 12 hours, Last 24 hours, Last 7 days)

* **Legend Information:**
  * Current queue size
  * Average queue size for the selected period
  * Visual indicators for each queue type

**Key Features:**
* Real-time queue size monitoring
* Historical trend analysis
* Visual identification of queue spikes and drops
* Average size calculations for capacity planning

**Use Cases:**
* Monitor system load and processing capacity
* Identify queue buildup that may indicate performance issues
* Track queue processing efficiency
* Plan capacity based on queue size trends

## External Queues Configuration

<img src="/tenant-management/screen-3.png" alt="Tenant Management - External queues configuration page" />

The External Queues page allows you to configure and manage external queue destinations for message streaming. This enables you to deliver events triggered by REST API operations to external streaming destinations.

### External Queue Configuration

**Configuration Management:**
* **ADD CONFIGURATION** - Click to add a new external queue configuration
* **MONITOR QUEUES** - Click to monitor external queue status and performance

**Configurations Table:**
The table displays all configured external queue destinations with the following columns:

* **Name/ARN** - The name or Amazon Resource Name (ARN) of the queue destination
* **Provider** - The service provider for the queue (e.g., Amazon SNS/SQS, Google Pub/Sub)
* **Streaming** - Toggle switch to enable or disable streaming for each configuration:
  * **Enabled** - Events are delivered to this external destination
  * **Disabled** - External delivery is paused, but internal pipelines continue to operate

**Key Features:**
* **Multiple Provider Support** - Configure queues for different cloud providers
* **Per-Configuration Control** - Enable or disable streaming for individual configurations
* **Configuration Management** - Add, edit, and manage external queue configurations
* **Monitoring Integration** - Monitor queue performance and delivery status

**Important Notes:**
* When streaming is disabled for a configuration, external delivery is paused, but internal pipelines such as Grouping and DataPipeline continue to operate if message streaming remains enabled
* The streamingAPIEnabled parameter in Tenant Configuration controls whether events are delivered to external destinations globally
* If you set streamingAPIEnabled to false while external queues are still configured, the UI displays a warning

**Use Cases:**
* Configure external message streaming to downstream systems
* Integrate with cloud messaging services (AWS SNS/SQS, Google Pub/Sub)
* Enable event-driven architectures
* Monitor external queue delivery performance

## Additional Tenant Management Features

### Statistics

View comprehensive tenant statistics including:
* Data volume metrics
* Entity counts
* Relationship statistics
* Source system contributions
* Data quality metrics

### Jobs

Manage and monitor tenant management jobs:
* **Analyze Match Strategy** - Analyze match token phrases and match rules performance
* **Data Load Jobs** - Monitor data loading operations
* **Reindex Jobs** - Track reindexing operations
* **Export Jobs** - Monitor data export operations
* View job history, status, and execution details

### Tenant Configuration

Configure tenant-level parameters:
* **Cleanse Configurations** - Configure address cleansing, verification, and processing
* **Nested Partial Override** - Enable partial override for nested attributes
* **Resolve Lookup Code** - Configure lookup code resolution
* **Tenant per Role Security** - Enable role reuse across tenants
* **Export File Compression** - Choose compression format for exported files
* **Match Strategy** - Configure match engine operation (Merge on the fly, Match only, etc.)
* **Search by Operational Value (OV)** - Enable search by operational values
* **Role-Based Access Control (RBAC) for RDM** - Configure RBAC for Reference Data Management
* **Message Streaming** - Control event delivery to external streaming destinations

**Configuration Modes:**
* **VIEWING Mode** - Default mode for viewing configuration parameters
* **EDITING Mode** - Select from the top-right corner to change tenant parameter settings

**Note:** Some changes require additional actions. Refer to each parameter's description for details.
