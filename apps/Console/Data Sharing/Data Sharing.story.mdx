# Data Sharing Overview

Reltio Data Sharing is an application in the Tenant Management group of the Reltio Console. Use it to securely share AI-ready, trusted data through zero-copy access or to export data using pipelines to cloud data warehouses.

<img src="./data-sharing-anatomy.png" alt="Data Sharing anatomy" />

Data Sharing is available only with a data integration add-on. It appears in the Console after your organization has subscribed to a specific integration. For context, see Reltio data integrations—add-ons.

Data Sharing combines functionality to give you the flexibility to choose zero-copy access or managed pipelines depending on your needs:
* Data Share provides a zero-copy integration between the Reltio Data Cloud and external cloud data warehouses such as Microsoft Fabric. Instead of relying on traditional ETL/ELT pipelines, you can deliver AI-ready, consumption-optimized data directly in supported platforms, reducing redundancy, lowering costs, and enhancing security and governance. See Data Share at a glance.
* Data Pipelines lets you create export data pipelines. Use it when you need to move data out of your tenant in the supported cloud data warehouses such as Databricks, Snowflake and GBQ for analysis, reporting, or downstream consumption. See Data Pipelines at a glance.
