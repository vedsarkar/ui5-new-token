# Console Overview

Console is a self-service tool for configuring data models, setting up integrations, and managing user roles and permissions, empowering organizations to tailor the platform to their specific business needs.

Console is perfect for users who prefer working through an intuitive interface rather than relying on technical expertise. It offers a streamlined, user-friendly platform that simplifies complex tasks, enabling self-service capabilities for configuration, workflow setup, and permission management.

Console is ideal for those who prefer to work in a User Interface.

Use Console for:
* Configuring the data model: Manage entity types, attributes, relationship types, match rules, survivorship rules, data validation functions, and more, ensuring your data structure aligns with your business needs.
* Setting up data integrations: Leverage the Reltio Integration Hub and Data Pipeline to establish integrations with source systems seamlessly.
* Overseeing tenant management: Monitor performance and usage metrics to optimize your tenant's efficiency.
* Managing security settings: Handle user management, configure SSO, and manage client credentials to ensure secure and streamlined access.
* Centralized view of data assets: The console provides a single, centralized view of all of your data assets, making it easy to find and access the data you need.
* Simplified data discovery: The console's intuitive interface makes it easy to discover new data assets and learn about their contents.
* Powerful querying capabilities: The console provides powerful querying capabilities that allow you to quickly and easily extract the data you need.
* Seamless integration with other Reltio tools: The console seamlessly integrates with other Reltio tools, such as the data quality tool and the data governance tool, making it easy to manage and govern your data.
