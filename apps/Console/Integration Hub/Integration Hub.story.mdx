# Integration Hub Overview

Reltio Integration Hub (RIH) is a data integration service offering over 1,000 prebuilt connectors and the ability to create custom integrations using a low-code/no-code platform. RIH enables seamless integration between Reltio and other systems, simplifying workflows and ensuring data consistency across platforms.

## Integration Hub Navigation

Access Reltio Integration Hub from Applications > Integration Hub. The application provides several key areas for building and managing integrations:

### Recipes Page

<img src="/integration-hub/screen-1.png" alt="Integration Hub - Recipes page" />

The Recipes page is the central workspace for creating and managing integration flows. The page is divided into three panels:

1. **Left Panel - Tools** - Lists tools you can use to create automated integration flows and monitor your processes
2. **Middle Panel - Assets** - Displays the assets you have created such as recipes, connections, and projects. You can search, filter, or list your recipes and connections as needed
3. **Right Panel - Details** - Shows a detailed view of the selected asset. You can create a new recipe or connection directly from this page

**Key Features:**
* Create new recipes or connections
* Search and filter existing recipes and connections
* View detailed information about selected assets
* Manage projects and organize your integrations

### Dashboard

<img src="/integration-hub/screen-2.png" alt="Integration Hub - Dashboard" />

The Dashboard page provides an interactive dashboard with filters to monitor integration performance:

1. **Recipe Summary** - Quick snapshot of all projects and recipes in terms of jobs and tasks. You can specify the period (e.g., last seven days), project, and/or recipe to view details
2. **Recipe Details Table** - Drill down into each recipe to view job or task details. Click on Successful jobs, Failed jobs, or Tasks count links to view detailed information
3. **Connection Details Panel** - Displays the count of active connections through your applications. You can disconnect or delete connections associated with listed accounts
4. **Job Monitoring** - Click a Job ID to view its recipe details, including execution status and performance metrics

**Dashboard Capabilities:**
* Filter by time period, project, or recipe
* View cumulative summary of recipes, jobs, and tasks
* Monitor successful and failed job executions
* Track task consumption across your integrations

### Community Library

<img src="/integration-hub/screen-3.png" alt="Integration Hub - Community Library" />

The Community Library provides access to a collection of pre-built and shared recipes:

1. **Recipe Categories** - Select relevant categories (e.g., Sales and Marketing) to filter recipes by application type
2. **Application Recipes** - Browse recipes for applications like Salesforce, Marketo, Snowflake, and many others
3. **Search and Browse** - Find recipes by scrolling, searching, or selecting categories
4. **Recipe Details** - View detailed information about each recipe before using it

**Benefits:**
* Access to pre-built integration recipes
* Fast time-to-value with ready-to-use connectors
* Learn from community-shared best practices
* Reduce development time by leveraging existing solutions

### Recipe Creation and Management

<img src="/integration-hub/screen-4.png" alt="Integration Hub - Recipe creation workflow" />

Creating an integration recipe involves a four-stage process:

**1. Launch Stage**
* Search the Community Library for existing recipes that might meet your use case
* Review pre-built recipes before deciding to create a new one

**2. Build Stage**
* Select the recipe starting point (Trigger) - determines when the recipe executes
* Select the trigger application (Source) and configure or select an existing connection
* Build the integration flow under Actions - define the steps your recipe will perform
* Configure the connector of the destination app and set up the mapping between source and destination

**3. Test Stage**
* Configure exception handling for the connector
* Activate the recipe and test by triggering an event in the source
* If test is successful, export the recipe for deployment
* If test fails, review the erroneous job, identify the step that appears in red, and resolve by editing the recipe

**4. Deploy and Monitor Stage**
* Import your recipe in the Production tenant
* Configure connections and activate the recipe
* Use the Dashboard page to monitor usage and job details

**Recipe Components:**
* **Trigger** - Determines when you would like to execute the recipe
* **Actions** - The steps that your recipe will perform
* **Application Connections** - Required connections for all applications that your recipe touches
* **Data Mapping** - Map data fields between source and destination systems using datapills

**Important:** Reltio Connector must be either a source, destination, or part of an intermediate step in each recipe created using Reltio Integration Hub.

## Key Features

* **No-code/Low-code Integration** - Build integrations between Reltio and third-party applications using a no-code or low-code platform
* **Pre-built Connectors** - Leverage rich selection of pre-built integrations to speed time-to-value
* **Integration Orchestration** - Connect and transform data across applications with high security, centralized monitoring, and recipe management
* **Intuitive User Interface** - Drag-and-drop mapping and user-friendly dashboards
* **Security** - End-to-end encryption with key rotation, masking, and retention settings
* **File Storage** - Manage files used in recipes, create directories, upload, download, rename, move, and delete files
* **Connected Apps Management** - View and manage all active connections, create new connections, disconnect or delete existing ones

## Use Cases

* **Data Integration** - Point-to-point integration with bulk load, bulk extraction of records, and real-time synchronization
* **Application Integration and Data Enrichment** - Enrich Reltio data with information from external systems
* **Data from Disparate Systems** - Make data from behind firewalls available in Reltio for all relevant stakeholders
* **Event Stream Ingestion and Delivery** - Enable secure and reliable bi-directional data exchange to mobile and web apps, IoT devices, and backend systems
* **Multicloud Data Sync** - Achieve complete customer views in a multicloud environment with sync of customer data across related applications
