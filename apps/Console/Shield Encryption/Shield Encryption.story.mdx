# Shield Encryption Overview

Reltio Shield is an add-on subscription service that provides transparent file data encryption using Customer-Managed Key (CMK) to protect your data. Shield enables you to create and manage your own encryption keys instead of relying on Reltio-managed keys, giving you full control over data encryption and compliance.

**Note:** Shield is supported on Amazon Web Services (AWS) and Google Cloud Platform (GCP) platforms. You must be a customer administrator with the ROLE_ADMIN_SHIELD role to access this application.

## Accessing Shield Encryption

To access Reltio Shield:

1. In the Reltio Console, under the **Tenant Management** section, select **Shield Encryption**
2. From the **Select tenant** dropdown menu, select the tenant for which you want to enable Shield encryption

## Shield Encryption Main Page

The Shield Encryption page displays the current encryption status and provides options to enable Shield encryption:

### Reltio Shield Status

The page shows the current status of encryption for the selected tenant:

1. **Shield enabled** - Reltio Shield is already enabled for the tenant. The encryption key is managed by you (Customer-Managed Key)
2. **Disabled** - Reltio manages the encryption key for the tenant. This is the default state
3. **Check permission and check subscription** - Indicates one of the following:
   * You may not have the required permission to access this feature
   * Your primary storage isn't DynamoDB (for AWS) or Spanner (for GCP)
   * You may not have Reltio Shield as part of your subscription package

### Key Management Options

The page provides information about key management:

* **Reltio-Managed Keys (Default)** - By default, Reltio creates and manages the encryption key for your tenant. Reltio will not use the key without explicit access
* **Customer-Managed Keys (Shield)** - You can take control of the encryption key by installing Reltio Shield. This allows you to generate your own Customer-Managed Key (CMK) and manage the encryption lifecycle yourself

### Enabling Shield Encryption

To enable Shield for a tenant:

1. **Select Tenant** - From the Reltio main menu, select the tenant for which you want to enable Shield encryption
2. **Verify Status** - In Reltio Shield Status, make sure that the status is **Disabled**
3. **Download Shield Script** - Click **DOWNLOAD RELTIO SHIELD** to download the encryption files. The `reltio-ondemand-dynamo-db-shield.zip` file is downloaded
4. **Extract Files** - Locate the downloaded zip file and extract its contents
5. **Run Installation Script** - Follow the installation process as explained in the documentation to create the encryption key and enable Shield

## Shield Features

Shield provides functionality grouped into three categories:

### Data Encryption

* **AES 256 Encryption** - Encrypts data held in Reltio using AES 256, one of the top encryption algorithms available today
* **Transparent Encryption** - Encryption is performed transparently without impacting customer experience or existing applications
* **Version Control** - Maintains encryption keys with version control. Previous keys are retained to ensure that old content (including from backups) can continue to be decoded
* **Automatic Key Selection** - Uses the most recent encryption key. Older keys are only used to decode older content

### Key Rotation

* **Manual Rotation** - Key rotations can be triggered manually in response to a security incident, such as when exposure of the current encryption keys occurs
* **Automatic Rotation** - New encryption keys can be created with a specified time-to-live and scheduled for automatic rotation
* **Zero Downtime** - Key rotations are performed live without system downtime. Shield automatically selects the correct key to decrypt data and the latest key to encrypt data
* **Background Re-encryption** - Re-encryption of data is performed as a background process, allowing access to live data during rotation
* **Rotation Period** - The Key Rotation Period can be set between six months (180 Days) and 2 years (730 Days)

### Operational Support

* **Audit Logs** - Detailed audit logs of Shield access are maintained, capturing activities such as when keys are created, when keys are rotated, and when changes to key rotation schedules are made
* **Monitoring and Alerting** - System health and performance monitoring tools help identify minor issues before they become major issues
* **Security Investigation** - Audit logs are a critical tool when investigating a security incident, helping to investigate specific incidents or look for unusual patterns of activity

## Key Material Options

When creating encryption keys, you can select the key material origin:

1. **AWS_KMS** - An Amazon Web Services KMS key. For this material origin, you can set a key rotation option to rotate the key automatically once every year
2. **EXTERNAL** - You provide your own key material file, which will be encrypted and imported to the key script generates. You need to have OpenSSL v.3.0 or later installed to use this option

## Platform-Specific Information

### AWS Platform

* Shield supports encryption of data residing in data stores managed by Reltio in AWS using Customer Managed Key (CMK)
* By default, your data stored in Reltio managed data stores is encrypted using AWS native encryption technologies
* Shield encrypts the files used by data stores within Reltio
* Encryption keys are never written to disk by Reltio services, reducing the chance of potential compromise

### GCP Platform (BYOK)

* Data for all tenants on Google Cloud Platform (GCP) is encrypted with Reltio-managed keys by default
* You can enable Reltio Shield as an add-on subscription to enable Bring Your Own Key (BYOK) functionality
* This enables you to bring your own keys to encrypt and protect your data while retaining ownership
* We recommend enabling Reltio Shield when creating a new tenant
* For existing tenants, enabling Shield requires data migration as it's not possible to change the keys for an existing database due to GCP restrictions

* **Transparent Encryption** - Encrypts data transparently without affecting existing applications or users with negligible performance degradation
* **Zero Downtime Key Rotation** - New keys can be generated on demand or automatically on a schedule with background re-encryption of data
* **Secure Key Distribution** - New keys are automatically distributed via secure automated processes, with no service downtime and without involvement or handling by Reltio staff
* **Comprehensive Audit Logging** - All activities performed on Shield are captured in audit logs, improving time to detect and time to resolve security issues
* **Fine-Grained Access Controls** - Protects data access via fine-grained access controls, supporting policies such as full access, administrative access, and blocked
* **Multi-Platform Support** - Supported on AWS and GCP platforms
* **Compliance Ready** - Helps your organization comply with common compliance and data privacy standards such as PCI DSS, HIPAA/Hitech, and GDPR
