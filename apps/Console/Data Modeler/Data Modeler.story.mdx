# Data Modeler Overview

The Data Modeler home page shows the entities, relationships and the sources that are available for the selected tenant.

<img src="./data-modeler-anatomy.png" alt="Data Modeller anatomy" />

In the Entity types page, each row summarizes the entity attributes, roles, and rules. An Inherited badge appears if the entity was inherited from a lower level of the hierarchy.

On the Entity types page, you can use the Sort and Filter icon () to sort the entity types in the order of Entity Types, No. of Attributes, Roles, or Rules. You can choose from any of the options listed in the Sort and Filter dialog box.

You can choose to view only the non-abstract entities or all the entities by using the appropriate option from the Filter By section in the Sort and Filter dialog box. By default, only the non-abstract entities are displayed.

Click an entity type to view information about its attributes, match rules, relationships, or roles. The Entity type's details page appears.
