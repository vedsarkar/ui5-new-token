# Reltio Icons

Reltio Icons are a custom, Reltio-branded icon set (application icons, entity-type icons, and product glyphs) that complements the standard SAP Fiori icons. They are authored as SVGs, vendored in the platform, and registered into UI5's global icon registry under the `reltio/*` namespace so they behave exactly like built-in SAP icons.

> **🎯 Key Principle:** Import the icons you use (per icon for tree-shaking, or the whole set for convenience), then render any of them by name with `<Icon name="reltio/<name>" />` — or pass that same name to any UI5 `icon` prop.

## 1. As UI5 icons (recommended)

### Step 1 — register the icons you use

Registering an icon is a side-effect import. There are two options — pick based on how much you care about bundle size.

**Per icon (recommended) — tree-shakable.** Import only the icons you actually use; your bundle includes only those SVGs. This mirrors SAP Fiori icons (`@ui5/webcomponents-icons/dist/save.js`):

```tsx
import "@reltio/design/icons/data-quality";
import "@reltio/design/icons/compare";
```

**The whole set — convenience.** A single import registers all `reltio/*` icons. Simplest to wire up, but pulls every icon into your bundle (use only when you genuinely need most of them, or in tooling/prototypes):

```tsx
import "@reltio/design/icons";
```

Either form is a one-time side effect — do it once, as early as possible (e.g. your root entry or layout). The icon stays registered globally for the rest of the app.

**✅ Do:** import per icon in app code

```tsx
import "@reltio/design/icons/contact";
```

**❌ Don't:** import the whole set in a size-sensitive app just to use a few icons

```tsx
import "@reltio/design/icons"; // bundles all 100+ icons
```

### Step 2 — render by name

Use the icon name `reltio/<name>` with the `Icon` component, or pass it to any UI5 component that accepts an `icon` prop:

```tsx
import { Icon, Button, SideNavigationItem } from "@reltio/design/components";

<Icon name="reltio/data-quality" />
<Button icon="reltio/compare">Compare</Button>
<SideNavigationItem icon="reltio/homepage" text="Home" />
```

The `<name>` is always the lowercase, kebab-case file name (see the [gallery](/?path=/story/icons-reltio-icons--gallery) for the full list).

### Sizing

Reltio icons render as inline SVGs that follow the surrounding `font-size`, or an explicit `width`/`height`:

```tsx
<Icon name="reltio/chart" style={{ fontSize: "1rem" }} />        {/* 16px */}
<Icon name="reltio/chart" style={{ width: "32px", height: "32px" }} />
```

### Color and theming

The icons are monochrome and paint with `currentColor`, so they inherit the surrounding text color and re-theme automatically between light and dark. Recolor via a SAP Horizon `--sap*` token or the semantic `design` prop:

```tsx
<Icon name="reltio/health-status" style={{ color: "var(--sapBrandColor)" }} />
<Icon name="reltio/health-status" design="Positive" mode="Image" accessibleName="Healthy" />
```

**✅ Do:** recolor with `--sap*` tokens or `design`

```tsx
<Icon name="reltio/anomaly" design="Negative" />
```

**❌ Don't:** hardcode hex colors

```tsx
<Icon name="reltio/anomaly" style={{ color: "#ff0000" }} />
```

### Accessibility

Same rules as the SAP `Icon`: decorative by default (hidden from assistive tech). When an icon carries meaning on its own, set `mode="Image"` and an `accessibleName`. For an icon-only action, prefer a `Button` with `icon` + `accessibleName`.

```tsx
<Icon name="reltio/shield-encryption" mode="Image" accessibleName="Encrypted" />
<Button icon="reltio/export-data" accessibleName="Export data" />
```

## 2. As static SVG assets (by URL)

The SVGs are published verbatim under the platform's public origin, so any non-UI5 surface can use them directly. The file name is the icon name plus `.svg`:

```html
<img src="https://reltio.design/icons/data-quality.svg" alt="Data quality" width="20" height="20" />
```

```css
.badge {
	background-image: url("https://reltio.design/icons/health-status.svg");
}
```

> **⚠️ Note:** A plain `<img>` renders the icon at its baked-in ink color and does **not** inherit `currentColor` or re-theme. Use the UI5 `Icon` path (option 1) whenever you need theming, semantic color, or icon-prop integration.
