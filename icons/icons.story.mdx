# Icons

The Reltio Design Platform ships two icon families — SAP Fiori icons and Reltio icons.

> **🎯 Key Principle:** Import each icon you use — its <code>default</code> export (the registry name) or its React component — which registers it (the package is <code>sideEffects: false</code>, so only imported icons ship). Then render the component, or pass the imported name to the <code>&lt;Icon&gt;</code> component's <code>name</code> prop or any Reltio Design Platform component's <code>icon</code> prop.

## SAP Fiori icons

The standard SAP icon set, browse the full set in the [SAP Fiori Icons explorer](https://ui5.github.io/webcomponents/icons/).

## Reltio icons

Custom, Reltio-branded icon set (application icons, entity-type icons, and product glyphs) that complement SAP Fiori icons.  They are authored as SVGs, vendored in the platform, and registered into global icon registry under the `reltio/*` namespace so they behave exactly like built-in SAP icons.

## 1. In your app (recommended)

### Step 1 — import the icons you use

Each per-icon module registers its icon **when you consume one of its exports** — its name (the `default` export) or its React component. There are no bare side-effect imports: the package is `sideEffects: false`, so importing only what you use is what keeps the icon registered *and* lets the bundler drop every icon you don't.

**Default export — the icon name (recommended for `icon` props).** The default export is the registry name string (`"save"`, `"reltio/data-quality"`), and importing it registers the icon:

```tsx
import saveIcon from "@reltio/design/icons/sap/save";
import dataQualityIcon from "@reltio/design/icons/reltio/data-quality";
```

**Component export — for standalone icons.** Every module also exports a PascalCase React component from the same path (importing it registers the icon too):

```tsx
import { Save } from "@reltio/design/icons/sap/save";
import { ReltioDataQuality } from "@reltio/design/icons/reltio/data-quality";
```

**The whole Reltio set — namespace import.** When you need every Reltio icon by name (e.g. a data-driven picker where the names aren't known at build time), import the barrel as a namespace and read the names off it; iterating it registers the whole set (and pulls every icon into your bundle — use only when you truly need them all):

```tsx
import * as reltioIcons from "@reltio/design/icons/reltio";

// e.g. reltioIcons.dataQuality === "reltio/data-quality"
const allReltioNames = Object.values(reltioIcons);
```

**✅ Do:** import just the icons you use

```tsx
import contactIcon from "@reltio/design/icons/reltio/contact";
```

**❌ Don't:** namespace-import the whole set in a size-sensitive app just to use a few icons

```tsx
import * as reltioIcons from "@reltio/design/icons/reltio"; // can bundle all 100+ icons
```

### Step 2 — render

Render the component directly, or pass the imported name to `<Icon>` / any Reltio Design Platform component that accepts an `icon` prop:

```tsx
import { Icon, Button, SideNavigationItem } from "@reltio/design/components";
import saveIcon from "@reltio/design/icons/sap/save";
import { ReltioDataQuality } from "@reltio/design/icons/reltio/data-quality";
import compareIcon from "@reltio/design/icons/reltio/compare";
import homepageIcon from "@reltio/design/icons/reltio/homepage";

// Component export — standalone icon
<ReltioDataQuality accessibleName="Data quality" />

// Name export — for the `icon` prop or <Icon name>
<Icon name={saveIcon} />
<Button icon={compareIcon}>Compare</Button>
<SideNavigationItem icon={homepageIcon} text="Home" />
```

The underlying name is always the lowercase, kebab-case file name (`save`, `reltio/data-quality`) — see the [catalog](/?path=/docs/icons-reltio-icons-catalog--docs) for the full list of Reltio icons or the [SAP Fiori Icons explorer](https://ui5.github.io/webcomponents/icons/) for SAP Fiori icons.

### Sizing

Icons render as inline SVGs that follow the surrounding `font-size`, or an explicit `width`/`height`:

```tsx
<Icon name="save" style={{ fontSize: "1rem" }} />                 {/* 16px */}
<Icon name="reltio/chart" style={{ width: "32px", height: "32px" }} />
```

### Color and theming

The icons are monochrome and paint with `currentColor`, so they inherit the surrounding text color and re-theme automatically between light and dark. Recolor via a SAP Horizon `--sap*` token or the semantic `design` prop:

```tsx
<Icon name="save" style={{ color: "var(--sapBrandColor)" }} />
<Icon name="reltio/health-status" design="Positive" mode="Image" accessibleName="Healthy" />
```

**✅ Do:** recolor with `--sap*` tokens or `design`

```tsx
<Icon name="reltio/anomaly" design="Negative" />
```

**❌ Don't:** hardcode hex colors

```tsx
<Icon name="reltio/anomaly" style={{ color: "#ff0000" }} />
```

### Accessibility

Decorative by default (hidden from assistive tech). When an icon carries meaning on its own, set `mode="Image"` and an `accessibleName`. For an icon-only action, prefer a `Button` with `icon` + `accessibleName`.

```tsx
<Icon name="reltio/shield-encryption" mode="Image" accessibleName="Encrypted" />
<Button icon="save" accessibleName="Save" />
```

## 2. As static SVG assets (by URL)

**Reltio icons only** — SAP Fiori icons are not published as standalone `.svg` files on `reltio.design`. Reltio glyphs are served verbatim from `public/icons/`.

The URL stem is the kebab-case file name (same segment as `@reltio/design/icons/reltio/<kebab-name>` and the part after `reltio/` in `<Icon name="reltio/<kebab-name>" />`) — **not** the full registry name:

```html

```

```css

}
```

> **⚠️ Note:** A plain `<img>` renders the icon at its baked-in ink color and does **not** inherit `currentColor` or re-theme. Use `<Icon>` from Reltio Design Platform (option 1) whenever you need theming, semantic color, or  icon-prop integration.

## Notes

> **Do not import `@ui5/webcomponents-icons` in application code.** The package arrives transitively via `@reltio/design`; register standard SAP icons through `@reltio/design/icons/sap/<kebab-name>`.
