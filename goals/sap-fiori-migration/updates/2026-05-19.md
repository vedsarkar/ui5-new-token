# Update — 2026-05-19 (Kick-off)

## Summary

Kick-off for the SAP Fiori migration goal. `@reltio/design` 1.0 is live with 42 of ~163 UI5 components endorsed (more coming), 7 Reltio components, 10 charts, Horizon theming, `@reltio/auth` 1.0, and a remote MCP at reltio.design/mcp. 0/16 apps migrated; pilots starting next.

## Key Accomplishments

### Platform foundation (in progress)

- `@reltio/design@1.0.0` shipped on May 12 — first stable distribution, pinned to `@ui5/webcomponents-react@2.21.3`, gated through Chromatic visual / interaction / a11y tests
- `@reltio/design@1.0.1` — Apache 2.0 relicensing aligned with upstream UI5
- `@reltio/design@1.0.2` — dependency-tree slim-down and correct `react` / `react-dom` peer ranges
- `@reltio/auth@1.0.0` — OAuth client with Express and Next.js App Router adapters (DESIGN-74)
- **42 of ~163 SAP Fiori (UI5) components currently endorsed (~26% surface coverage)** — Avatar, Button, Calendar (+ Date/Time pickers), CheckBox, ComboBox, FileUploader, Icon, Input, MessageStrip, MultiInput, Popover, RadioButton, RangeSlider, SegmentedButton, Select, Slider, SplitButton, StepInput, Switch, Token, and more. The remaining ~120 components will be added incrementally as apps adopt the package
- 7 Reltio business components / primitives — `AppSelector`, `Chat` (with `<Chat.Composer />`), `Details`, `ErrorBoundary`, `Markdown`, `Skeleton`, `TextArea`
- 10 ECharts visualisations in `@reltio/design/charts` — `BarChart`, `Diagram`, `DonutChart`, `GaugeChart`, `GeoChart`, `GraphChart`, `LineChart`, `RadarChart`, `SankeyChart`, `SetOverlapChart`
- Hooks (`useTextStream`) and utilities (`classNames`, `HtmlProps`, value-state / form-type helpers)

### Design system access for every team

- **Remote Reltio Design MCP at <https://reltio.design/mcp>** — any team (or AI agent) can query the live component catalogue, full JSON Schemas, JSDoc-annotated types, and raw stories source in real time, without installing Storybook locally
- Static CSS hosted at <https://reltio.design> — `variables.css` (SAP Horizon tokens, light + dark) and `fonts.css` (SAP 72) — consumers reference the URLs directly from `<head>` and themes activate by setting `data-theme="horizon-light" | "horizon-dark"`
- Apache 2.0 license aligned with the upstream `@ui5/webcomponents-react` license — removes legal ambiguity for customers and partners that redistribute Reltio apps

### Tooling & documentation

- Changesets-based versioning, automated release PRs on `main`, Bitbucket Pipelines builds both `@reltio/design` and `@reltio/auth` bundles
- OpenSpec workflow for spec-driven changes; first archived change is `2026-05-14-add-auth-package`
- Storybook guides for UI Architecture, Spec-Driven Development, Reltio Design MCP, Auth Setup (Next App Router + Express), and Auth Migration from legacy `auth-middleware`

### Application inventory captured

- All 16 Reltio UI applications documented under `apps/` with tech stacks, routes, deployment targets, and migration entry points
- 13 of 16 app source repositories wired as git submodules (May 17–18) — `reltio-react-ui`, `admin-tools`, `rdm-react`, `workflow-ui`, `ui-config-tool`, `data-modeller`, `bpmn-modeler`, `data-out`, `env-management`, `dataloader-ui`, `ui-export`, `external-match-ui`, `usage-reporting-ui`
