## Key Accomplishments

### Endorsed surface established (42 components)

- **42** named UI5 re-exports in `components/index.ts` — form controls (Button, Input, CheckBox, Select, ComboBox, MultiComboBox, Switch, and related items), date/time (Calendar, DatePicker, DateRangePicker, DateTimePicker, TimePicker, DynamicDateRange), feedback (MessageStrip, BusyIndicator, Avatar), layout primitives (Popover, Icon, Token), and more
- Each export has Storybook documentation and is reachable via `@reltio/design/components` and the remote MCP at <https://reltio.design/mcp>
- Endorsement model is **documentation-only** (no runtime wrappers) — scales to the remaining ~143 components without duplicating UI5 implementations

### Platform releases anchoring the baseline

- `@reltio/design@1.0.0` (12 May 2026) — first stable distribution on `@ui5/webcomponents-react@2.21.3`
- `@reltio/design@1.0.1` — Apache 2.0 license alignment
- `@reltio/design@1.0.2` — dependency tree cleanup and correct React peer ranges

### Explicit exclusions documented

- `ProductSwitch` / `ProductSwitchItem` not endorsed — `AppSelector` is the canonical cross-product navigator
- Target **185** = 189 UI5 public components minus 4 infrastructure / replaced entries
