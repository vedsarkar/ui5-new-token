# Components

Browse the full component surface in one place — the **union** of the SAP Fiori (UI5) React catalog and the Reltio Design catalog. This single filterable page shows both the **intersection** (UI5 components Reltio endorses) and the **differences** (UI5 components not yet endorsed, and Reltio-only components and charts with no UI5 equivalent). Filter by status or category, search by name, and follow the **UI5 React** / **Reltio Design** links on each row.

> **🎯 Source of truth:** Generated from <code>{data.source}</code> by `scripts/build-component-data.mjs` (`npm run build-component-data`). Counts and links are derived from the installed package, the barrel in `components/index.ts`, the `charts/` directory, and the UI5 React Storybook index — never hand-edited.

The table records two independent axes: the **Status** (Reltio's stance) and the **UI5 React** lifecycle. Filter them separately — e.g. set **UI5 React → Deprecated** to see every component SAP has retired (charts included), regardless of what Reltio does with it.

## What the columns mean

- **Status** (Reltio's stance) — `Endorsed` (reachable from `@reltio/design/components`), `Backlog` (UI5 component not yet endorsed — includes stable and experimental candidates), `Excluded` (intentionally not shipped — see the note; includes UI5-deprecated components we don't plan to build), or `Reltio` (Reltio-only component or chart with no UI5 counterpart).
- **UI5 React** (UI5 lifecycle) — the underlying UI5 component: a link to the canonical SAP docs, `Experimental` / `Deprecated` for components SAP marks as unstable or retired, or `—` when UI5 has no equivalent. Filterable on its own axis.
- **Reltio Design** — how Reltio ships it (`1:1`, `renamed`, `wrapper`, `custom`) plus a link to the endorsed Storybook page, or `—` when Reltio does not ship it.

## Scope

- The **entire** UI5 React surface is listed across its lifecycle (stable / experimental / deprecated), filterable via the **UI5 React** column.
- **Charts** are shown as `Reltio` entries with a `Deprecated` UI5 lifecycle: the UI5 React charts package (`@ui5/webcomponents-react-charts`) is SAP-deprecated, so Reltio ships its own ECharts-based charts (see **Charts**).

## Adding a component

To endorse a backlog component, follow the doc-only / wrapper flow in [`components/AGENTS.md`](https://bitbucket.org/reltio-ondemand/reltio-design/src/main/components/AGENTS.md), then re-run `npm run build-component-data` so this page reflects the new coverage.
