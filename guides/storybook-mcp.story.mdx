# Storybook MCP

The Reltio Design Platform publishes a remote [Model Context Protocol](https://modelcontextprotocol.io/) server powered by [Storybook MCP](https://storybook.js.org/blog/storybook-mcp-for-react/). It gives AI agents direct access to every component, story, design token, and API contract documented in this workspace — no copy-paste, no guesswork.

```
https://reltio.design/mcp
```

> **What does it do?** The MCP server exposes Storybook documentation and stories as structured context that AI coding agents can discover, read, preview, and test — the same content you browse here, but machine-readable.

## Setup

### Claude Code

Create a `.mcp.json` file in the root of your project:

```json
{
  "mcpServers": {
    "reltio-design": {
      "type": "http",
      "url": "https://reltio.design/mcp"
    }
  }
}
```

Or add it via the CLI:

```bash
claude mcp add reltio-design --type http --url https://reltio.design/mcp
```

The server will be available in all Claude Code sessions within that project.

### Cursor

Add the server to `.cursor/mcp.json` in your project root:

```json
{
  "mcpServers": {
    "reltio-design": {
      "type": "http",
      "url": "https://reltio.design/mcp"
    }
  }
}
```

After saving, open Cursor Settings > MCP and verify "reltio-design" appears in the server list with a green indicator.

### VS Code (Copilot)

VS Code has built-in MCP support for GitHub Copilot Chat. Add the server to `.vscode/mcp.json` in your project root:

```json
{
  "servers": {
    "reltio-design": {
      "type": "http",
      "url": "https://reltio.design/mcp"
    }
  }
}
```

The MCP tools will be available in Copilot Chat agent mode.

### Claude.ai (Web)

Claude.ai supports remote MCP servers through the Integrations settings.

1. Open [claude.ai](https://claude.ai) and go to **Settings > Integrations**
2. Click **Add integration** and select **Custom MCP**
3. Enter the server URL: `https://reltio.design/mcp`
4. Name it **Reltio Design**
5. Save — the tools will be available in all new conversations

### ChatGPT

ChatGPT supports MCP servers in its desktop app.

1. Open ChatGPT and go to **Settings > Tools**
2. Click **Add tool** and select **Connect MCP server**
3. Enter the URL: `https://reltio.design/mcp`
4. Name it **Reltio Design** and save

### Any MCP-Compatible Client

The server uses the standard HTTP (Streamable HTTP) transport. Any client that supports remote MCP servers can connect using the URL:

```
https://reltio.design/mcp
```

If your client uses `npx mcp-add`, the one-liner is:

```bash
npx mcp-add --type http --url "https://reltio.design/mcp" --scope project
```

## What Agents Can Do

Once connected, an AI agent can use the Reltio Design MCP server to:

- **Discover components** — list all available components, their props, and variants before writing code
- **Read documentation** — fetch the full docs for a specific component, including usage guidelines and API reference
- **Preview stories** — get live preview URLs to visually verify component states
- **Run tests** — execute interaction and accessibility tests directly from the chat
- **Follow conventions** — understand the project's design tokens, typography, icon library, and coding patterns

### Example Prompts

Once the MCP server is connected, try asking your AI agent:

> "List all available Reltio components"

> "Show me the documentation for the Button component"

> "What props does the Dialog component accept?"

> "Run accessibility tests for the Checkbox stories"

> "What design tokens are available for colors?"

## Local Development

When working on the Reltio Design Platform itself, you can connect to the local Storybook dev server instead of the remote endpoint. Start Storybook first:

```bash
npm run dev
```

Then use `http://localhost:6006/mcp` as the URL in any of the configurations above. The `.mcp.json` in this repository already points to the local server for development.
