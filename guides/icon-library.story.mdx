# Icon Library Guide

Reltio applications render icons through `@reltio/design` — the SAP Fiori icon set in the Horizon visual style, plus Reltio product glyphs. SAP icons register at `@reltio/design/icons/sap/<kebab-name>`; Reltio icons at `@reltio/design/icons/reltio/<kebab-name>`. Render with `<Icon name="…" />` from `@reltio/design/components`.

> **🎯 Key Principle:** Use `<Icon name="..." />` from `@reltio/design/components`. Register SAP icons with `import "@reltio/design/icons/sap/<kebab-name>"` and Reltio icons with `import "@reltio/design/icons/reltio/<kebab-name>"`.

## Usage

### 1. Register the icon (tree-shakable side-effect import)

Separate import paths per family — register only the icons you use:

```ts
import "@reltio/design/icons/sap/save";
import "@reltio/design/icons/reltio/data-quality";
```

Each side-effect import registers a single icon in the global icon registry. Only the icons you import end up in the bundle.

### 2. Render with `<Icon>`

The render `name` depends on the family:

```tsx
import { Icon } from "@reltio/design/components";
import "@reltio/design/icons/sap/save";
import "@reltio/design/icons/reltio/data-quality";

// SAP Fiori — bare kebab name
<Icon name="save" />

// Reltio icons — reltio/ prefix
<Icon name="reltio/data-quality" />
```

```tsx
import { Icon } from "@reltio/design/components";
import "@reltio/design/icons/sap/save";

function SaveButton() {
	return (
		<button type="button">
			<Icon name="save" />
			Save
		</button>
	);
}
```

### 3. Optional PascalCase component export

Every per-icon module exports a named component from the same path:

```tsx
import { Decline } from "@reltio/design/icons/sap/decline";
import { ReltioDataQuality } from "@reltio/design/icons/reltio/data-quality";

<Decline design="Negative" accessibleName="Close" />
<ReltioDataQuality accessibleName="Data quality" />
```

### 4. Use icons inside other components by name

Most `@reltio/design` components that accept an icon (e.g. `Button`, `MessageStrip`, `ListItem`) expose an `icon` prop that takes the same name string. As long as the icon module is imported once anywhere in the app, the name resolves globally.

```tsx
import { Button } from "@reltio/design/components";
import "@reltio/design/icons/sap/save";

<Button icon="save" design="Emphasized">Save</Button>;
```

### Icons from non-default collections

Prefix the icon `name` with the collection identifier:

```tsx
import { Icon } from "@reltio/design/components";
import "@ui5/webcomponents-icons-tnt/dist/network.js";

<Icon name="tnt/network" />;
```

> Non-default collections (`tnt`, `business-suite`) are not re-exported from `@reltio/design` in v1 — install `@ui5/webcomponents-icons-tnt` or `@ui5/webcomponents-icons-business-suite` and import their modules directly, as shown above.

## Sizing

`<Icon>` renders an SVG that follows the surrounding `font-size` (or explicit `width`/`height`).

```tsx
<Icon name="save" style={{ fontSize: "1rem" }} />     {/* 16px */}
<Icon name="save" style={{ fontSize: "1.5rem" }} />   {/* 24px */}
<Icon name="save" style={{ width: "32px", height: "32px" }} />
```

Inside a button or a row of text, simply leave the size to the surrounding `font-size` — the icon will match the line height naturally.

## Color

By default `<Icon>` paints with `currentColor`, so it inherits the parent's text color. To switch palette, set `color` on the icon (or any ancestor) to a SAP Horizon `--sap*` token:

```tsx
<Icon name="save" style={{ color: "var(--sapBrandColor)" }} />
<Icon name="status-positive" style={{ color: "var(--sapPositiveColor)" }} />
<Icon name="status-negative" style={{ color: "var(--sapNegativeColor)" }} />
<Icon name="status-critical" style={{ color: "var(--sapCriticalColor)" }} />
```

`<Icon>` also supports semantic `design` values that map to standard SAP token combinations (e.g. `Negative`, `Positive`, `Critical`, `Information`, `Neutral`, `Contrast`, `Default`):

```tsx
<Icon name="status-positive" design="Positive" />
<Icon name="status-negative" design="Negative" />
```

## Theming

Icons automatically follow the active SAP theme through the `data-theme` cascade — no React provider needed:

```tsx
<div data-theme="sap-reltio-light">
	<Icon name="status-positive" design="Positive" /> {/* light-theme positive color */}
</div>

<div data-theme="sap-reltio-dark">
	<Icon name="status-positive" design="Positive" /> {/* dark-theme positive color */}
</div>
```

See the [Design Tokens guide](./?path=/docs/design-tokens--docs) for how the cascade reaches components through Shadow DOM.

## Accessibility

Icons are decorative by default — they are hidden from assistive tech unless you opt in.

**Decorative icons** (default) — when the icon accompanies visible text or surrounding context conveys the meaning:

```tsx
<button type="button">
	<Icon name="save" />
	Save
</button>
```

**Meaningful icons** — when the icon is the only content of an interactive element (e.g. icon-only button), provide an accessible name:

```tsx
<button type="button" aria-label="Save">
	<Icon name="save" accessibleName="Save" />
</button>
```

For icon-only buttons, set `accessibleName` on the `Button` itself:

```tsx
<Button icon="save" accessibleName="Save" />
```

## Updating the Icon Set

SAP Fiori icons ship through `@reltio/design` at the version the CoE has tested. To pick up new SAP icons, bump `@reltio/design` — do not install or import `@ui5/webcomponents-icons` directly in application code.

For non-default collections (`tnt`, `business-suite`), install the separate npm packages and import their modules directly — these are not yet re-exported from `@reltio/design` in v1.

## Best Practices

**✅ Do:** Register icons via `@reltio/design/icons/sap/<kebab-name>`

```ts
import { Icon } from "@reltio/design/components";
import "@reltio/design/icons/sap/save";

<Icon name="save" />;
```

**❌ Don't:** Import `@ui5/webcomponents-icons` in application code

```ts
import "@ui5/webcomponents-icons/dist/save.js";
```

**❌ Don't:** Import every icon globally at the app root — defeats tree-shaking

`@reltio/design` ships SAP Fiori icons only as per-icon modules (`@reltio/design/icons/sap/<kebab-name>`). There is no all-SAP-icons aggregate import.

For the Reltio custom set, a convenience barrel exists — use it only when you genuinely need most icons (prototypes, tooling):

```ts
// Bundles every Reltio icon in the package
import "@reltio/design/icons/reltio";
```

**✅ Do:** Use semantic colors via `--sap*` tokens or `<Icon design="...">`

```tsx
<Icon name="status-positive" design="Positive" />
<Icon name="warning" style={{ color: "var(--sapCriticalColor)" }} />
```

**❌ Don't:** Hardcode hex colors

```tsx
<Icon name="warning" style={{ color: "#ff8c00" }} />
```

**✅ Do:** Let icons inherit `currentColor` inside text and buttons

**❌ Don't:** Force a fixed size on icons inside flex/text containers — let `font-size` drive it
