# Icon Library Guide

Reltio Design uses the SAP Fiori icon set distributed by [`@ui5/webcomponents-icons`](https://sap.github.io/ui5-webcomponents/), rendered in the Horizon visual style. Icons are rendered by UI5 React's `<Icon>` component. There is no Reltio-specific icon component — we consume UI5's set directly so that every Reltio surface stays visually aligned with the rest of the SAP ecosystem.

> **🎯 Key Principle:** Use `<Icon name="..." />` from `@ui5/webcomponents-react`, and import the icon's data module from `@ui5/webcomponents-icons` to register it on demand.

## Usage

### 1. Register the icon (tree-shakable side-effect import)

```ts
import "@ui5/webcomponents-icons/dist/save.js";
import "@ui5/webcomponents-icons/dist/navigation-down-arrow.js";
```

Each side-effect import registers a single icon's SVG data with UI5's icon registry. Only the icons you import end up in the bundle.

### 2. Render with `<Icon>`

```tsx
import { Icon } from "@ui5/webcomponents-react/Icon";
import "@ui5/webcomponents-icons/dist/save.js";

function SaveButton() {
	return (
		<button type="button">
			<Icon name="save" />
			Save
		</button>
	);
}
```

### 3. Use icons inside UI5 components by name

Most UI5 components that accept an icon (e.g. `Button`, `MessageStrip`, `ListItem`) expose an `icon` prop that takes the same name string. As long as the icon module is imported once anywhere in the app, the name resolves globally.

```tsx
import { Button } from "@ui5/webcomponents-react/Button";
import "@ui5/webcomponents-icons/dist/save.js";

<Button icon="save" design="Emphasized">Save</Button>;
```

### Icons from non-default collections

Prefix the icon `name` with the collection identifier:

```tsx
import { Icon } from "@ui5/webcomponents-react/Icon";
import "@ui5/webcomponents-icons-tnt/dist/network.js";

<Icon name="tnt/network" />;
```

## Sizing

`<Icon>` renders an SVG that follows the surrounding `font-size` (or explicit `width`/`height`).

```tsx
<Icon name="save" style={{ fontSize: "1rem" }} />     {/* 16px */}
<Icon name="save" style={{ fontSize: "1.5rem" }} />   {/* 24px */}
<Icon name="save" style={{ width: "32px", height: "32px" }} />
```

Inside a button or a row of text, simply leave the size to the surrounding `font-size` — the icon will match the line height naturally.

## Color

By default `<Icon>` paints with `currentColor`, so it inherits the parent's text color. To switch palette, set `color` on the icon (or any ancestor) to a SAP Horizon `--sap*` token:

```tsx
<Icon name="save" style={{ color: "var(--sapBrandColor)" }} />
<Icon name="status-positive" style={{ color: "var(--sapPositiveColor)" }} />
<Icon name="status-negative" style={{ color: "var(--sapNegativeColor)" }} />
<Icon name="status-critical" style={{ color: "var(--sapCriticalColor)" }} />
```

UI5 also exposes a small set of semantic `design` values on `<Icon>` that map to standard SAP token combinations (e.g. `Negative`, `Positive`, `Critical`, `Information`, `Neutral`, `Contrast`, `Default`):

```tsx
<Icon name="status-positive" design="Positive" />
<Icon name="status-negative" design="Negative" />
```

## Theming

Icons automatically follow the active SAP theme through the `data-theme` cascade — no React provider needed:

```tsx
<div data-theme="horizon-light">
	<Icon name="status-positive" design="Positive" /> {/* light-theme positive color */}
</div>

<div data-theme="horizon-dark">
	<Icon name="status-positive" design="Positive" /> {/* dark-theme positive color */}
</div>
```

See the [Design Tokens guide](./?path=/docs/design-tokens--docs) for how the cascade reaches UI5's Shadow DOM.

## Accessibility

Icons are decorative by default — UI5 hides them from assistive tech.

**Decorative icons** (default) — when the icon accompanies visible text or surrounding context conveys the meaning:

```tsx
<button type="button">
	<Icon name="save" />
	Save
</button>
```

**Meaningful icons** — when the icon is the only content of an interactive element (e.g. icon-only button), provide an accessible name:

```tsx
<button type="button" aria-label="Save">
	<Icon name="save" accessibleName="Save" />
</button>
```

For icon-only UI5 buttons, the equivalent prop is `accessibleName` on the `Button` itself:

```tsx
<Button icon="save" accessibleName="Save" />
```

## Updating the Icon Set

The icon set is shipped by `@ui5/webcomponents-icons`. To pull in newer SAP icons, bump the package alongside the rest of the UI5 stack:

```bash
npm update @ui5/webcomponents @ui5/webcomponents-react @ui5/webcomponents-icons
```

For non-default collections:

```bash
npm install @ui5/webcomponents-icons-tnt
npm install @ui5/webcomponents-icons-business-suite
```

There is no in-repo "source" folder for icons — every SVG comes from the installed package at runtime.

## Best Practices

**✅ Do:** Register icons via side-effect import at the call site

```ts
import { Icon } from "@ui5/webcomponents-react/Icon";
import "@ui5/webcomponents-icons/dist/save.js";

<Icon name="save" />;
```

**❌ Don't:** Import every icon globally at the app root — defeats tree-shaking

```ts
// Bundles every icon in the package
import "@ui5/webcomponents-icons/dist/AllIcons.js";
```

**✅ Do:** Use semantic colors via `--sap*` tokens or `<Icon design="...">`

```tsx
<Icon name="status-positive" design="Positive" />
<Icon name="warning" style={{ color: "var(--sapCriticalColor)" }} />
```

**❌ Don't:** Hardcode hex colors

```tsx
<Icon name="warning" style={{ color: "#ff8c00" }} />
```

**✅ Do:** Let icons inherit `currentColor` inside text and buttons

**❌ Don't:** Force a fixed size on icons inside flex/text containers — let `font-size` drive it
