The Reltio Design System provides a comprehensive icon library with 44+ Material Design 3 icons. Icons are available through two access patterns: direct URL access for raw SVG files and npm imports for React components.

## Access Patterns

### 1. Direct URL Access (CDN)

Raw SVG files are served from the public folder and accessible via URL:

```
https://reltio.design/icons/chevron-down.svg
https://reltio.design/icons/account-circle.svg
```

Use this pattern when you need:
- Raw SVG files for non-React applications
- Embedding icons in external tools or documentation
- Using icons in CSS as background images

### 2. NPM Package Import (React)

Import React components for full functionality:

```tsx
import { ChevronDown, AccountCircle } from "@reltio/design/icons";

function MyComponent() {
  return (
    <div>
      <ChevronDown size="medium" />
      <AccountCircle color="primary" />
    </div>
  );
}
```

### `className`

Add custom CSS classes:

```tsx

```

Apply inline styles, including CSS custom properties:


Add accessible label for meaningful icons:

```tsx

```

## Accessibility

Icons support two accessibility modes:

### Decorative Icons (Default)

When no `aria-label` is provided, icons are hidden from screen readers:

```tsx
// Decorative icon - hidden from screen readers
<Search />
// Renders with aria-hidden="true"
```

Use decorative icons when:
- The icon accompanies visible text
- The icon is purely decorative
- The meaning is conveyed by surrounding context

### Meaningful Icons

When `aria-label` is provided, icons are announced to screen readers:

```tsx
// Meaningful icon - announced to screen readers
<Search aria-label="Search" />
// Renders with role="img" and aria-label="Search"
```

Use meaningful icons when:
- The icon is the only content in a button
- The icon conveys information not available in text
- The icon is interactive without surrounding text

## How to Add a New Icon

Adding icons is automated through a generation script:

### Step 1: Add SVG File

Place your SVG file in `public/icons/` using kebab-case naming:

```
public/icons/my-new-icon.svg
```

SVG requirements:
- Use 24×24 viewBox (Material Design 3 standard)
- Use outlined style for consistency
- Remove fixed colors (use currentColor for fill)

### Step 2: Run Generation Script

Execute the icon generation script:

```bash
node scripts/generate-icons.mjs
```

This automatically generates:
- React component: `icons/MyNewIcon.tsx`
- Storybook stories: `icons/MyNewIcon.stories.tsx`
- Updated barrel export: `icons/index.ts`
- Updated manifest: `icons/manifest.json`

### Step 3: Format Code

Run the formatter to ensure consistency:

```bash
npm run format
```

### Step 4: Verify in Storybook

Start Storybook to verify your new icon:

```bash
npm run dev
```

Your icon will appear in:
- The Icon Library grid
- Individual icon story pages

## Best Practices

1. **Use semantic colors appropriately** - Success for positive actions, Warning for caution, Error for destructive actions
2. **Always provide aria-label for icon-only buttons** - Screen reader users need context
3. **Keep sizes consistent** - Use the standard size props rather than custom sizes
4. **Prefer React components over raw SVGs** - Better tree-shaking and type safety
5. **Follow naming conventions** - Use kebab-case for files, PascalCase for components
