# Reltio Design Platform

Unified R&D ecosystem for building, testing, and documenting UI across all Reltio products and external integrations.

## Mission

Eliminate UI fragmentation across products while accelerating development of new applications and features.

## Core Principles

- **Single source of truth** — one platform for all UI-related assets and knowledge
- **Everything as code** — components, tests, documentation, guidelines, configs, AI instructions
- **AI-ready by design** — prepared for integration with AI agents via MCP-UI and A2UI

## Key Artifacts

- **UI Components & Design Tokens** — reusable building blocks and theming system
- **Patterns & Layouts** — proven solutions for common UI challenges
- **Storybook Stories** — documentation + tests + demos + specifications in one artifact
- **Technical Guides** — rich MDX guidelines for developers and product teams
- **Domain-specific utils & data-hooks** — client API SDK for business logic

## Audience

**Internal:**
- **Developers** — build applications with shared components and patterns
- **Designers** — reference specifications and design tokens
- **QA Engineers** — use stories for visual, interaction, and accessibility testing
- **Product Managers** — review features and user flows

**External:**
- **Partners** — integrate Reltio UI into their solutions
- **Customers** — embed components via "component marketplace"
- **AI Agents** — interact via MCP-UI and A2UI protocols
